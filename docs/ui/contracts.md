## 入口与内容

军团视图只展示军团自身名义发布、指定给军团或由军团接受的合同；仅向联盟开放且与军团无关的合同不展示。后端在分页前过滤，详情深链接及 CSV 遵守相同范围，管理员也不能通过该视图打开范围外合同。没有新增“联盟合同”菜单、筛选或冗长提示；个人合同沿用原范围。

类型按官方游戏语义展示物品交换、拍卖、快递运输；ESI 保留的 loan／unknown 放入下拉框“兼容数据”分组，loan 标为“借贷（历史）”，列表、详情和 CSV 共用名称。交易方向是本站根据明细推导的独立字段，不是游戏合同类型，不加入类型筛选。官方核对来源见[合同接入](../integrations/contracts.zh-CN.md#合同类型)。

导航入口 `/contracts`。个人／军团切换与对象选择在列表上方，列表卡片内包含描述或 ID 搜索、类型、状态、刷新和分页。个人默认按当前账号绑定角色选择；管理员从 `/members` 选择成员后，以 member 参数进入该成员的有效角色范围，并保留返回成员资料入口；军团下拉只包含后端判定允许查看的军团。

列表工具栏新增下载图标“导出合同（CSV）”，导出当前所选角色／军团及已提交的搜索、类型、状态筛选下全部分页合同；忽略当前页游标。导出中按钮切换为取消，提示已读取数量；成功由浏览器下载，错误在工具栏下方显示短提示，不下载部分结果。切换范围、筛选、账号或离开列表会取消进行中的导出。详情不新增导出入口，不导出物品和出价明细。

CSV 使用中文列名、UTF-8 BOM，包含标题及原始描述、方向、双方与接收人、地点、金额和 ISO 8601 时间。空描述摘要及接收人优先级与列表一致；最多 10,000 条，超过时要求缩小筛选而非静默截断。沿用 44px IconAction，不增加常驻说明卡片；空结果、权限失效与导出失败分别反馈。

600px 及以下工具栏为搜索一行、类型／刷新一行、状态／导出一行，筛选框占剩余宽度，按钮固定 44px，避免增加图标后截断选项文字。导出截图见[contracts-export](reviews/contracts-export/)，使用测试数据。

列表显示类型图标、标题、状态、交易方向、发起方头像、接收人、金额和到期时间。快递显示报酬，其他合同显示价格／起拍价。优先显示原始描述；空描述使用完整物品明细生成摘要：单种物品为“名称 × 合计数量”，多种物品为“首种名称等 N 种物品”，双向交换区分“提供／换取”；名称遵循 SDE 中文优先。快递使用起点 → 终点。无法生成时回退合同类型；合同 ID 始终作为次级信息，不覆盖原始描述。摘要不参与搜索。点击标题或箭头进入详情；URL 查询参数保留范围、对象、筛选、分页历史与合同 ID，详情可以直接打开，返回后保留列表位置。

交易方向以发起方为准：出售、求购、交换、运输；明细不完整或无法判定时显示待确认，不按价格猜测。列表使用独立窄列，详情标题下使用同一短标签；1100px 及以下改为分组行，在发起方右侧保留方向。

接收人优先显示实际接受者，没有接受者时显示指定对象；公开且未接受／未指定时显示“公开”，其他缺失显示“未指定”。窄屏在发起方下增加接收人行，双方保留短标签，详情仍分别列出指定对象与接受方。

详情按合同概况、物品和出价分区。金额在一个浅底区域内展示；合同双方、时间和地点集中在概况卡片。物品显示 EVE 图标、名称、提供／要求、数量和蓝图类型；拍卖另展示出价人、精确金额与日期。快递不展示包裹内物品。

## 排版与状态

- 角色／军团、合同类型、合同状态均使用共享 Radix Select 封装，替代浏览器原生展开列表。44px 触发器、8px 圆角；面板为白底、12px 圆角、细边框与轻阴影，选项浅蓝高亮并显示勾选，角色／军团增加 26px 头像或徽标。选项保持官方值与兼容分组，空值仍表示全部。浮层通过 Portal 避开卡片裁切，间距 6px、视口边距 12px、最高 360px 并可滚动；键盘与窄屏记录见 [contracts-select](reviews/contracts-select/)。这些参数仅为本页及当前组件实现，不强制改造其他页面。

- 加载优化：当前地址对应页面代码提前下载；指定角色／军团链接在登录确认后并行读取范围与合同列表／详情，范围确认前保留加载提示。没有指定对象时仍等待范围返回后选择默认对象。合同标题或查看按钮在指针进入／键盘聚焦时预取该条详情；导航、列表与预取共享查询缓存，不增加缓存有效期，不显示其他对象的旧数据。页面布局与正文不增加说明。

- 合同状态仅对应 ESI 官方十项，中文对照见[合同状态](../integrations/contracts.zh-CN.md#合同状态)。列表、详情与 CSV 使用同一映射；outstanding 显示“未完成”，reversed 显示“已逆转”。单方完成与整体完成的颜色／图标分开，仅 finished 显示整体完成标识；悬停状态可查看原始值。不从截止时间生成“已过期”，不混入同步状态。

- 每个区域只由一层承担 24px 内边距；手机适配 20px。不设置填满视口的最小卡片高度。
- 桌面列表使用表格阅读顺序；窄屏改为逐条分组，金额和操作保留，到期时间可在详情查看。320px 不产生页面横向溢出。
- 常见操作沿用 44px `IconAction`，短业务标签保留文字。筛选有可访问名称；进入详情后聚焦详情标题。
- 金额使用十进制字符串分组显示，避免 JavaScript Number 丢失精度；极长金额在分组边界换行。
- 名称查询不可用时展示 `#ID`，头像／物品图标失败使用同尺寸 Lucide 后备。不把未解析名称误认为无数据。
- 缺失、加载、筛选为空、无范围权限、读取失败和明细未完成分别展示。未完成或失败的明细提示内容可能不完整；尚未抓取的出价不能显示为“没有出价”。
- 页码、金额和日期使用等宽数字；状态同时使用文字及语义颜色。减少动态效果时移除位移及缩放。

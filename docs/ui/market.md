# 物品估价与多级导航

沿用 Corporate Clean；用 ui-ux-pro-max 补充键盘导航、可见焦点和移动端适配。

估价页面：顶部标题、吉他 4-4 与管理员比例图标；粘贴输入区保留紧邻的估价按钮。结果用三张价格卡比较收购价/中间价/出售价，突出中间价，卡片显示原价与比例折算额；明细按物品、数量、三种数量合计价排表，缺报价用文字状态加颜色提示。行情日期在物品下以次级文字显示。小屏卡片纵排，只有明细表在有边界的容器内横向滚动。输入失败保留内容，估价进行中禁用重复提交；比例编辑复用 Modal。

导航为工作台直达，加四个折叠组：作战与训练（出勤、配装、技能、损失）、财务与工具（钱包、合同、物品估价）、福利与兑换（福利、兑换）、系统管理（成员、权限、ESI 同步、系统状态）。我的角色仍在账号入口。页面声明 navigationGroup，统一模块注册表负责入口与路径；不创建新路由副本。

桌面默认仅展开当前页所在组，每次打开一组收起其他组；切换页面或前进后退自动展开目标组。组触发器为原生 button，aria-expanded/aria-controls 对应子列表，Enter/Space 可操作；子页保留 aria-current，折叠后移出键盘序列。手机默认折叠菜单，用“菜单”按钮打开，选页后重新收起；桌面侧栏独立滚动。保留跳转正文入口与路由后正文焦点。先按启用模块与权限过滤再分组，空组不显示。

本次导航改变不修复或重新开启历史 Edge 卡顿调查。验证覆盖 1440、375、320px、比例弹窗、错误/部分结果、组折叠与键盘操作；截图在 reviews/market，演示数据不代表真实市场联调。

# ESI 同步页面

2026-09-20 令牌桶密度优化：最近响应时间与身份、快照状态放在同一组，配额数字/容量、用量条和滑动窗口放在另一组，累计消耗及请求数保持独立；保留原有数字、单位及未知语义。行上下内边距 16px、组内间距 6px。布局按列表实际可用宽度切换：720px 起为身份/配额/消耗/展开横行；480–719px 身份另起一行；480px 以下展开按钮置于身份右侧，下方两列显示指标。接口明细同步按容器宽度重排。桌面列表维持全宽，不缩窄外层卡片；展开图表、计量口径与查询行为不变。

钱包新增个人/军团余额、流水、市场交易与军团分部名称共 7 类资源标签，复用同步运行记录与重试入口。缺少游戏职务仅延迟重新检查，不发送军团钱包 ESI 请求。


2026-09-14。遵循 [通用规范](../ui-design-rules.md)；ui-ux-pro-max 仅补充异步反馈、可访问性与响应式检查。

- `/account` 在现有角色详情卡底部按资源嵌入状态行，不增加说明卡或统计卡。各行包含资源、图标状态、最近成功时间和刷新操作；错误原因按需出现。重新授权仍使用角色的既有授权入口。
- `/sync` 使用一个列表卡，顶部搜索与状态筛选，角色头像/名称、资源、状态、最近成功、下次执行及图标操作对齐。执行记录按需展开；不在任务表堆叠长说明或凭据原文。令牌观测另用同页“登录令牌”页签，见下节。
- 状态不能只靠颜色；刷新、重试、记录按钮有可访问名称与焦点样式。排队和成功使用不同文案，提交失败保留操作入口。无权限、空数据、加载和服务不可用有明确状态。
- 桌面多列，窄屏重排为两列信息，不强制拉高卡片。长角色名换行，320px/375px 无横向溢出；沿用项目配色、圆角、留白和减弱动效约束。
- 列表卡外壳取消默认纵向 padding，仅由内容层负责内边距，避免 Card 与 CardContent 叠加成双倍留白。
- 活动任务前台每 5 秒更新，其他每 30 秒；后台标签页停止定时刷新。管理员只看到具有独立同步管理权限的入口。

## 令牌观测（2026-09-14）

- `/sync?view=tokens` 用 Radix 页签切换，保留一个页面主标题；页签由图标配短标签组成，方向键可切换，URL 保留当前视图。任务查询和令牌查询按当前页签启用。
- 令牌每角色一行，显示头像/名称、状态及 scope 数、访问令牌到期、最近刷新成功、请求/缓存次数和记录图标。刷新、搜索、记录复用 44px IconAction，状态筛选使用统一 Select。
- 复用计数、刷新统计、时间、精简请求异常与最近 20 条事件按需展开，长 scope 列表进一步折叠。到期是按需刷新，不用红色将正常过期渲染成失效。
- 列表内边距桌面 24px、手机 16px；行按实际内容布局，不设置大最小高度。详情指标桌面四列、手机两列。标题的默认下边距在本页面清零，避免与 24px grid gap 叠加。
- 缺失时间显示“—”，历史凭据无有效期时显示“尚未观测”。“有效期内”只陈述本地有效期；异常时显示可读原因。元数据权限为 `eve.sync.manage`，没有修改或显示原始令牌的入口。
- 沿用 Corporate Clean；ui-ux-pro-max 的表格窄屏重排建议用于避免页面溢出，未重新选择风格。

模拟数据检查：[桌面](reviews/tokens/desktop-1440.png)、[375px](reviews/tokens/desktop-375.png)、[320px](reviews/tokens/desktop-320.png)。覆盖长名称、成功/失败/未知、记录展开、空/错误重试、权限隐藏、键盘页签及下拉焦点返回；截图不是生产角色状态。

## 限流令牌桶（2026-09-14）

- `/sync?view=rate-limits` 新增“令牌桶”，原“令牌”改称“登录令牌”；保持原深链接兼容。三个页签支持键盘，手机减少横向 padding 并保留 44px 高度。
- 一张列表卡展示桶分组、角色/公共出口、剩余/容量及计量累计消耗。原生 meter 以品牌色显示最近响应配额，不当成实时余额；快照时间与窗口直接展示。
- 展开显示本地估算、预算恢复、ESI 重试与累计起点，及每个规范化接口的请求/缓存、累计/最近/平均消耗、等待/限流。计量缺失明确标注，0 与未知区分。详细口径仅留一句必要说明，完整解释在中英文接入指南。
- 桌面横行，手机先分组身份，再配额/消耗两列，展开接口按两列重排；长接口可换行。沿用 Corporate Clean 单层卡片与 24px/16px 内边距，无新设计系统或图表库。
- 本页前台每 30 秒读本地元数据；展开接口独立查询、折叠停止轮询，翻页按桶/接口各 30 项；刷新图标不会访问 CCP。搜索、空/失败重试和权限门禁沿用统一组件。

## 令牌桶图表与配额来源（2026-09-15）

- 替代上节的纯表格默认展示：展开桶后先看 ECharts 横向消耗图，按已计量累计消耗降序，最多显示本页前 10 项；图表/明细切换使用 44px 图标操作，键盘和触屏可查看本页所有数字与完整接口路径。
- 配额用量条保留原生 meter，状态配 Lucide 图标；官方目录与响应配置明确标注。缺少余额仍显示“—”，不出现“未识别分组”；未计量柱项明确标记，不画作零消耗。下一笔恢复与累计起点分开，没有时间序列就不绘制趋势。
- 共享组件位于 `web/src/components/charts/`，ECharts 按展开懒加载，SVG/柱条/网格按需引入；颜色和字体从统一 CSS 主题读取。图表透明底、品牌蓝、二维圆角柱条，动画不超过 200ms，减少动态效果关闭动画。ResizeObserver 跟随容器大小；关闭时销毁实例。
- 同一份指标图表/表格渐进展示，移除重复说明段落；界面继续保留三层字号、单层卡片与中等密度。图表提供可读摘要，触屏不用悬停就能读数，窄屏未计量标签换行。
- 使用 ui-ux-pro-max 的比较图及可访问性建议，未改主题。视觉证据仍位于本页 `reviews/rate-limits/`，为模拟响应数据，不代表真实 CCP 配额。

2026-09-15 修复：训练队列加入同步响应类型白名单，混合资源列表不再误报读取失败；角色页复用同一解析器。运行记录保留等待原因，中断任务显示“任务中断，等待重试”。不改变版式、主题和调度规则。

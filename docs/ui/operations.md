# 军团运营面板

## 当前首版

`/operations` 是面向拥有 `access.manage` 范围的管理者的运营汇总页，放在“作战与训练”导航组。页面复用现有业务接口，不新增统计表、迁移或写操作。

首版展示：

- 当前可管理军团的成员数公开快照；
- 当前月军团 PAP、活动数与参战记录数；
- 近 7 日在线成员与在线时长；
- 审批中心待审批、待发放、异常、待补充的分布；
- 最近活动列表，可直接进入活动详情；
- 公开击毁数量、击毁价值和在线采样覆盖。
- 财务情况只按军团钱包统计总余额和本月税收，并分别展示近六个月钱包净变化趋势与税收趋势；成员个人钱包仍在独立的成员收入报表中统计。
- 集结情况按本月活动统计 PAP、活动场次、已结算和待结算活动；补损资金按本月案件统计待结算占用、已完成发放和案件数。
- 集结情况同时显示联盟 PAP 满足率，按本站有效绑定的自然人去重后，将同一账号的多个角色合计，再与管理员配置的月度目标比较；快照未完整同步时显示不可用。
- PAP、补损和在线区块提供紧凑折线趋势图，按本月周段或近 7 日采样展示；成员收入使用月度折线图，数据不足时保留空态，不补造趋势。图表使用固定绘图区高度、卡片内宽度约束和可收缩坐标轴，避免柱条或标签溢出卡片。
- 运营面板的 ISK 金额统一取整显示；大额使用 K/M/B 紧凑单位，图表提示与坐标刻度保持相同格式，避免长数字撑开报表。

数据不可用时显示短横线或不可用状态，不把缺失数据当作零。公开数据只在当前军团与 Glory Navy 公共投影一致时展示，管理员明细仍通过成员、考勤、审批和钱包页面查看。

## 排版与响应式

- 顶部为军团名称、军团选择和刷新；第一行四个指标卡，宽屏四列，中屏两列，小屏单列。
- 下方按“待办分布／财务报表／成员收入”和“集结／补损、近期活动／公开运营”分组排版；重复的“运营脉搏”卡已移除，避免同一组 PAP、在线和击毁数据重复出现。
- PAP 使用紧凑环形进度，活动和公开数据保留数字与明细入口；不堆叠解释性段落。
- 财务情况采用紧凑排版：总余额、税收两项指标并排，下面并列展示钱包趋势和税收趋势；趋势使用固定高度折线图，避免明细表和收支对比条造成重复信息，移动端改为上下堆叠。
- 所有跳转、刷新和选择控件复用统一图标、下拉和焦点样式；支持减少动态效果。

## 边界与后续

本页的“军团成员”来自公开军团快照，不等同于本站自然人数量；在线数据按现有在线采样口径计算。财务卡片读取管理员可读的军团钱包，以及当前军团成员有效绑定角色的个人钱包快照；成员数据读取需要 `access.members.read`，没有有效快照时显示不可用。补损统计只读取管理员可见的本月案件，不能用成员额度投影冒充军团总额；案件分页或来源不可用时显示不可用。福利成本、成员留存趋势和自定义时间范围仍待后续服务端聚合接口。

- “成员收入变化”使用同一权限范围的本地钱包快照，展示近六个月总收入、本月收入、本月有收入成员数和月度折线趋势；缺少快照的月份保持零高度，不把失效凭据或军团钱包混入。财务卡片的余额、税收和两条趋势均来自管理员可读军团分部的本地钱包日志，按 UTC 月份去重最新观测。

## 页面结构

- `/skills`：一个主标题，右侧角色选择和刷新；身份、技能点、未分配 SP、满级数量合并一张概览卡。
- 技能总览：中文/ID 搜索、技能分类、两列紧凑技能行；五格条和数值共同表达等级。生效等级不同时补充一行，避免把等级限制误读成训练缺失。
- 训练队列：按官方位置排序，突出当前训练，展示目标等级、状态、结束时间和日期估算进度。默认隐藏已完成条目，可勾选显示。
- 军团要求：军团/方案选择，要求清单、逐角色可展开的达标结果；有权限时显示新增、编辑、删除及军团检查范围。每页 50 个角色，返回首页/下一页；改变方案或范围重置游标。
- 方案编辑使用对话框和中文/英文/ID 搜索，只能添加官方技能类型；要求等级 1–5，删除用图标与可访问名称。保存期间锁定表单；删除需要确认。

2026-09-16：编辑统一为公共 `Modal`（桌面最大 640px），标题/关闭按钮与“技能数量＋保存要求”固定可见，内容区单独滚动；初始焦点放方案名称。删除改用公共 `ConfirmDialog`（最大 440px），显示目标名称，默认聚焦取消；失败留在弹窗内重试。配装生成技能方案复用同一编辑弹窗；桌面 24px、手机 20px 内容内边距，375/320px 按视口收窄，不另设外层皮肤。

## 密度与状态

2026-09-17：未达标角色名称下显示“还差 X SP”，达到全部要求时仅保留“已达标”状态，不显示剩余 0 SP；未知显示“剩余 SP —”。展开后仅未达标／未知项在技能名称下显示对应缺口，等级与状态沿用右侧排布。使用现有辅助文字、千分位与表格数字，不增加统计卡或常驻解释。长角色名和数字可换行，手机不横向溢出。取值规则见[技能接入指南](../integrations/skills.zh-CN.md)。

卡片 24px 内边距，页面区块 24px 间距；手机适配 20px，技能列表和要求列表转单列，指标自适应两列。不套装饰性统计卡，不放开发说明。图标按钮沿用项目 Tooltip/焦点和触屏尺寸；等级条附可访问数值，进度使用原生 progress。CDN 失败保留头像尺寸。

无数据、空队列、缺授权、请求失败单独处理。有可读快照时，后台同步及同归属重新授权期间保留技能、指标和队列，不显示“待更新”，成功后直接替换；保持上次同步时间，首次无数据才显示“待同步”。缺授权提示去“我的角色”授权。数据新鲜度仍由后端计算，军团要求待确认不渲染为零级不达标。刷新重新读取本站快照，不声称立即完成 ESI 同步。

成员只读模式有简短标记，军团要求管理权限独立按调用者核对。接口不因按钮隐藏而跳过后端鉴权。截图验证使用隔离的浏览器接口夹具，不创建或替换真实登录会话。

达标检查沿用最近可读的历史技能/队列快照，不因后台同步或缓存过期切为“待确认”，不增加“待更新”标记；新数据返回后重新计算。仅首次无数据、授权失效、缺失观测或记录冲突继续待确认。现有 60 秒轮询和结果布局不变。

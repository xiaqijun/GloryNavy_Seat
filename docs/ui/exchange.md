### 配置入口集中到奖励库（本地）

/rewards 统一维护奖品内容及兑换设置。每张奖励卡显示上架状态，提供“兑换设置”自动核算每份吉他中间价，修改库存和上下架；内容通过编辑图标修改。顶部提供 PAP 比例/模式和果壳币价值。配置表单按需打开共享弹窗，一次一个；果壳币价值与 PAP 比例/模式使用 440px，奖品兑换设置使用 640px。标题与底部取消/保存固定，正文滚动；提交防重、错误保留、关闭返回触发按钮，下拉与弹窗分级 Esc 关闭；编辑内容后仍需重新上架。实物库不含币，福利发币继续独立配置。

/exchange 使用 scope=listed，服务端在分页前筛选已上架、未停用奖品；奖励库配置使用管理员 scope=all。管理员仍能处理兑换订单，不改变余额、历史订单或交付流程。

### 奖励吉他中间价（本地）

兑换设置的金额字段统一为“价值”，旁边标注 ISK。打开时按吉他中间价自动填入，管理员可修改为最终每份价值（1–10^12 整数 ISK）；下方吉他中间价及行情时间仅为参考，不把手填金额标为市场价。核价期间禁用输入和保存；缺价/失败后可手填并保存。点击重新核价，成功完整报价替换输入，失败保留手填值；保存后固定价格、历史订单不变。中英文同步，沿用既有异步状态和 44px 操作区。

# LP 兑换查询

“工具 → LP 兑换查询”，路径 `/lp`。Corporate Clean，沿用统一 Select、Button、IconAction 与浅色语义。独立工具分组只在 LP 模块启用时显示，不改既有资产／福利入口。

筛选按阵营、可搜索的 NPC 军团、市场、售价依据、税费排列；桌面五列，1200px 以下三列，560px 以下两列，军团占两列。结果为全宽紧凑表格，25 项一页，材料按行展开。900px 以下每项改为两列标签／数值布局，物品名和单位收益占满一行；不产生页面横向滚动。金额使用 M/B/T，精确值保留 title；关键状态不依赖颜色。

搜索同时覆盖中英文、ID 与蓝图产物，多词全部匹配。筛选、排序和市场变化重置分页；加载与失败保留商店条件，禁止旧报价展示为新结果。税费无效、缺价、无配方分别阻止收益计算；上游失败有重试。选择器支持键盘与 Esc 返回焦点，输入有可见标签，操作至少 44px。计算口径折叠展示，避免默认文字堆积。

验证范围：桌面 1440px、手机 375px/320px，中英文、搜索、翻页、材料、税费、空军团、报价失败及恢复。模拟浏览器验证与真实 ESI/行情联调分别记录在项目状态，不能相互替代。

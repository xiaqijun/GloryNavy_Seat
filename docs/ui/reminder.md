# 提醒页面

2026-10-30 本地未发布：QQ群建筑提醒配置保存成功使用右下角浮动通知；配置状态、发送记录和错误仍在原位显示。

普通邮箱提醒（已发布）：管理员在提醒页面配置 SMTP 发件与提醒类型并查看发送状态；成员在“我的角色”验证并启停自己的邮箱。与游戏内邮件和 QQ 群提醒分开，授权码只写。桌面、手机和中英文使用模拟数据检查；真实收发待验收，实际状态见项目状态。

邮箱配置更换服务器或发件账号时，表单提示重新填写 SMTP 授权码；启用状态下未填写时不能提交。只修改其他配置且账号和服务器不变时，可留空沿用已保存授权码。

`/reminders`，reminder 模块，系统管理分组；导航与页面按当前站点管理员显示，后端独立鉴权。沿用 Corporate Clean、统一 Card/Button 和中英文词表。

页面用全宽配置区与发送记录表。配置区仅“游戏内邮件”、发件角色、“授权发信”、推送总开关、保存，以及提醒类型多选；不用常驻说明小字。初始关闭；未授权不能启用，授权失败保留角色选择。SSO 返回错误、保存版本冲突及网络失败在操作位置以错误色显示；授权角色不符时点明所需角色，另区分会话失效、缺少发信权限及无管理权限。版本冲突可刷新配置。未保存内容不随后台记录刷新丢失。

1280px 配置横排，480px 以下角色选择独占一行，其余按钮自动换行。列表不收窄；320/375px 时仅表格内部横向滚动，不撑开页面。记录显示时间、收件主角色、提醒类型、数量、状态、操作；只有明确失败显示重试，未知结果不提供重复发送按钮。每页 50 条、按时间/ID 游标分页，每 30 秒刷新当前页。

日期使用 `getLocale()`，角色名不翻译，空/加载/失败状态明确。设置与发送记录接口仅管理员读取，表单写入使用 CSRF；登录普通成员不能通过直接地址取得配置。

2026-10-18：类型按可用来源显示，独立于总开关，支持全选和清空。类型区使用 14rem 最小列宽的自适应网格，窄屏单列，每项 44px 可点击高度；不用额外说明小字。未选择类型时不能开启推送。保存失败保留选择；记录刷新不重置编辑。

同时启用 community 与 structures 模块时，页面显示独立的“QQ群建筑提醒”卡片。军团从现有可见军团列表选择，现有军团缺少列表名称时保留当前选项；群目标使用官方机器人群 OpenID，不接受数字群号。保存需 revision 和 CSRF；无改动不保存、不改变监测基线，失败保留输入并提供刷新。卡片展示启停状态、机器人不可用或更换提示，以及当前可查看军团最近 50 条 QQ 发送记录。不提供不确定结果的重试。移动窄屏将记录行排成带字段标签的纵向列表，时间、内容与状态均无需横向滚动；桌面保留紧凑表格。具体权限、事件和回退边界见[提醒指南](../integrations/reminder.zh-CN.md)。

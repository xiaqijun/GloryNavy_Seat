# 提醒页面

`/reminders`，reminder 模块，系统管理分组；导航与页面按当前站点管理员显示，后端独立鉴权。沿用 Corporate Clean、统一 Card/Button 和中英文词表。

页面用全宽配置区与发送记录表。配置区仅“游戏内邮件”、发件角色、“授权发信”、待审批开关、保存；不用常驻说明小字。初始关闭；未授权不能启用，授权失败保留角色选择。SSO 返回错误、保存版本冲突及网络失败在操作位置显示；版本冲突可刷新配置。未保存内容不随后台记录刷新丢失。

1280px 配置横排，480px 以下角色选择独占一行，其余按钮自动换行。列表不收窄；320/375px 时仅表格内部横向滚动，不撑开页面。记录显示时间、收件主角色、待办数、状态、操作；只有明确失败显示重试，未知结果不提供重复发送按钮。每页 50 条、按时间/ID 游标分页，每 30 秒刷新当前页。

日期使用 `getLocale()`，角色名不翻译，空/加载/失败状态明确。设置与发送记录接口仅管理员读取，表单写入使用 CSRF；登录普通成员不能通过直接地址取得配置。

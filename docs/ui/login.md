## 目标与内容

让用户识别 GloryNavy 并通过 EVE Online 登录。页面应有品牌表现力，文字保持精简。

- 使用独立布局，不展示工作台侧栏、顶栏、模块导航或系统状态。
- 正常状态可见文字与操作仅保留品牌和 EVE 登录按钮；不添加平台副标题、重复登录标题、口号、操作说明、权限数量、技术清单或环境文字。
- 保留供辅助技术识别的页面标题。错误和未配置提示按需出现，不为减少文字隐藏操作失败原因。
- 使用现有 EVE SSO 入口，不新增账号密码、QQ/KOOK 登录入口、注册表单或资料补全步骤。
- 权限详情由 EVE 官方授权页面展示；开发者配置说明放在文档。

## 构图与装饰

当前实现记录（2026-09-14）：桌面采用左侧低饱和舰船主视觉、右侧白色登录区，手机采用上下排列；品牌旁为 Glory Navy 官方军团图标。资源来源见[图片记录](../../web/public/images/README.md)。此段记录当前页面，不将具体图片或分栏比例升级为全站规则。

- 继承浅色 Corporate Clean：品牌蓝、灰白背景、白色操作区、细边框、统一圆角与轻阴影。
- 设置一个主要品牌视觉区域，可选品牌标记、几何插画、抽象舰队或轨道图形；按整体构图选择，不将这些元素全部堆叠。
- 必要时搭配一种低对比背景纹理或浅色分区。装饰不能穿过按钮、错误提示或可读文字，不能拦截交互。
- 桌面可采用品牌区与登录区分栏，也可采用单卡片构图；按内容决定比例，不用多余文字填充留白。此处不指定此前任何草案为最终方案。
- 登录按钮是唯一主操作，使用足够留白和清晰对比建立层级；装饰不能比操作更抢眼。
- 不添加虚构统计、伪状态灯、装饰性坐标或看似实时的星图数据。装饰默认静态，不使用循环粒子、强发光、复杂 3D 或厚重阴影。
- EVE 登录标识沿用现有官方按钮资源；资源加载失败仍提供可识别、可点击的文字按钮。
- 品牌旁使用 Glory Navy（G.N.V，军团 ID `98530802`）的官方军团图标，保留原色；不再使用通用盾牌代替。该品牌资产不改变其他 UI 组件的蓝灰白主题。

## 响应式

- 手机优先保障品牌、按钮及必要状态。装饰可转为顶部区域、缩小或局部裁切，不将桌面双栏等比例压缩。
- 短屏先减少装饰高度和留白。正常状态的登录按钮应在首屏可达；错误变长时允许自然滚动，不固定容器高度裁掉内容。
- 按全局规范保留移动端内边距，按钮不小于 44×44 CSS px。窄屏与文字放大时允许换行，不出现横向溢出。

## 登录状态与反馈

| 状态 | 页面行为 |
| --- | --- |
| 检查会话与配置 | 显示等待图标及可访问状态名称，预留操作区尺寸，避免布局跳动 |
| 可登录 | 显示唯一 EVE 登录主按钮 |
| 提交中 | 禁止重复提交，提供忙碌反馈；从授权页返回后可再次操作 |
| 取消或授权失败 | 原位显示简短原因与恢复方式，保留登录入口；不显示令牌或底层异常 |
| 服务不可用 | 显示简短提示和有中文可访问名称的重试图标 |
| 尚未配置 | 显示联系管理员的必要提示，不展示可用登录按钮 |
| 已有会话 | 无回调错误时进入 `/account`；有错误时先保留错误并提供返回账号入口 |

成功回调进入 `/account`；账号信息采用工作台布局，不属于本登录页的视觉规范。渲染异常使用宿主错误边界，网络与授权失败按实际状态显示，不能用错误边界代替异步错误处理。

## 可访问性与实现

- 使用原生按钮和链接，键盘可操作、焦点清晰且不被装饰遮挡。图标操作必须有中文可访问名称。
- 正常文字对比度至少 4.5:1，大字至少 3:1；低对比装饰不能承担关键含义。保留全局焦点与减少动态效果规则。
- 纯装饰 SVG 使用 `aria-hidden="true"` 且不可聚焦，装饰图片使用空 `alt`。有实际含义的品牌链接仍有名称。
- OAuth 登录无需在本站增加记忆、谜题或手工转录验证码任务；不为“认证感”添加无需求的交互门槛。
- 简单图形优先 CSS/SVG，图片预留尺寸；静态装饰不引入大型渲染或动画依赖。React 中显式处理异步失败，提交状态恢复后允许重试。

## 验收

2026-09-20 状态补查：SSO 官方按钮图片加载期间也显示当前语言的登录文字，加载成功后替换为图片，加载失败保留文字。避免 CDN 慢响应时按钮只剩黑色底块；按钮可访问名称及 SSO 提交行为不变。

- 检查桌面、375px 手机及短屏；品牌可识别、登录入口突出、无多余文案、无横向溢出。
- 检查键盘操作、焦点、文字放大、减少动态效果及图片失败回退。
- 检查加载、提交、返回、取消、失败、未配置与已有会话状态，确保装饰不影响恢复操作。
- 当前文件定义验收要求，不表示新视觉已经实现或全部状态已经通过验证。

## 页面与入口

- `/` 为公开军团介绍，保留给未登录和已登录访客；右上角为 EVE 登录，已有本站会话时显示“进入工作台”。原工作台迁至 `/workspace`，侧栏与“返回工作台”指向新地址。
- 首页来自 system 模块的 `system.landing` 声明，入口只挂载这一个经审查的本地公开页面，不请求模块目录、管理权限、审批、钱包或 PAP。查询现有 session 以选择登录/工作台按钮，并请求明确白名单的 /api/v1/eve/public/corporation 和 /api/v1/eve/public/activity 展示公开资料及用户批准的在线汇总；任一服务失败均不阻断介绍和招募。
- EVE 按钮复用现有同源 POST `/api/v1/eve/login`。`/login` 继续提供登录错误、未配置状态和重试；回调仍进入 `/account`，资料门禁、绑号、重新授权与后台鉴权均不改变。未登录访问 `/workspace` 仍进入登录页。
- 顶部导航为“关于我们 / 军团实力 / 舰队生活 / 加入我们”，页面内锚点定位。招募联系方式由用户明确提供：复制 QQ 群号 **674743797**，KOOK 指向 `https://kook.vip/h9CYhU`，新标签使用 noopener/noreferrer。复制失败时群号仍可手工复制；不自动入群、发送消息或关联社区身份。

- 固定文案有中英文词表，语言切换保留当前页面。按钮至少 44px，复制反馈可由读屏读取，纯装饰近景为空 alt。公开区突出本军团规模、在线角色汇总及公开击毁，提供本军团战绩外链；不展示钱包、资产、PAP、名单或未经确认的福利承诺。界面使用“角色”标签，不将多开数量标为自然人数。

# 快递服务页面

入口 /courier，统一模块注册并置于财务与工具；沿用 Corporate Clean、统一 Select、IconAction 和中英文词表。

2026-10-23：终点下拉仅展示服务方地点名称（例如 Jita），不拼接运输类型，也不新增运输类型控件；仍用路线 ID 选择对应的运费、容量与期限。合同复制继续使用原始地点名称，不擅自将星系名替换为具体空间站。

桌面两栏：左侧货物、估价与路线，右侧运费、规则和合同复制。1050px 以下单列，320px 输入及总计改为一列。无多余说明小字，服务方以页头链接标识；规则和错误直接显示。暂停路线不进入选项，按服务方地点分类与优先级排列。自动估价与手动填写切换时清零额外数值，编辑清单清除原报价；复制字段精确整数，长金额使用 M/B/T。

错误、未识别物品、容量溢出及路线加载失败保留明确提示与重试；未得到可用结果禁用复制。复制失败可手动选中只读字段。下拉沿用键盘与焦点行为，所有操作至少 44px。验收覆盖中英文及 1280/375/320px、路线错误/空/暂停、清单失败/修改、最小收费/超量和复制精度；结果见项目状态，模拟浏览器验收不替代实际运输。

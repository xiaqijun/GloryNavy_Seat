2026-09-23 已发布：公开 `/` 改为[军团介绍首页](homepage.md)，工作台迁移到 `/workspace`。下列工作台业务口径不变；此前首页直接进入登录的行为仅适用于旧生产版本。

## PAP 来源与管理员待办（2026-09-22）

工作台展示当前月联盟 PAP 摘要，详情进入“军团考勤 → 联盟 PAP”；军团 PAP 仍在考勤页单独统计，不混用联盟达标口径。联盟快照不可用时显示不可用状态，不把缺失数据当作 0。工作台审批待办仅当前站点管理员可见，读取 access/me 失败或非管理员均不挂载待办组件、不请求队列；生产已启用 approval，并保留 welfare / exchange 来源。此项限定首页区域，不更改审批中心既有业务授权和专用页面流程。

2026-09-25 已发布 `v0.1.0-workspace-approval-fast-20260925`：管理员身份确认后，工作台并行读取审批上下文与待办列表，不再等上下文返回才请求列表；列表接口仍逐来源鉴权。普通成员及权限读取失败仍不请求待办。待审批列表与审批中心复用同一账号隔离缓存，30 秒内导航返回可直接显示已取数据；真实链路耗时仍以项目状态为准。

2026-09-25 已发布 `v0.1.0-approval-navigation-prefetch-20260925`：首个完整的管理员待办列表显示后，工作台逐类预读其余审批分类；指向或键盘聚焦分类时优先预取。点击已预读分类直接使用同账号的短期缓存，未完成的分类继续显示读取状态，分类计数在请求期间保留上一个已知完整统计。权限未确认、非站点管理员或来源部分故障时不启动后台分类预读。


适用范围：`/workspace` 与 `/system`。继承[通用 UI 规范](../ui-design-rules.md)。以下为当前页面需求与实现参数，不是全站通用要求。

## 工作台（2026-09-21，本地改版）

- `/workspace` 为业务工作台：当前主角色、绑定角色摘要、果壳币可用余额/兑换占用/累计消费、本月联盟 PAP、个人钱包收支速度、常用入口和最近五条本人兑换。角色主身份与本次登录角色分离，角色列表优先主角色，最多显示六个，完整列表进入“我的角色”。
- 联盟 PAP 使用服务器当前月快照，显示联盟 PAP 环形达标进度、月度目标与最多三个角色的积分，点击进入联盟 PAP 子页。军团 PAP 不在工作台重复展示；两者仍在考勤页分别统计和兑换。
- 个人钱包明细仅预览前三个绑定角色，主角色优先，不再用下拉逐个切换；其余角色通过“查看全部”进入钱包页。顶部余额合计与读取数量仍覆盖全部绑定角色，不受三条预览限制。每行显示角色头像、角色名、余额及快照时间，点击进入对应钱包；未获可读授权或停用角色显示不可读取并进入角色页。只列本人角色，不混入军团分部资金，也不读取管理员可查看的其他成员。钱包顶部突出合计金额，收入与支出采用并排的扁平指标区，不嵌套小卡片；配方向图标、ISK/日与“本月日均”标记。钱包卡片显示本月日均收入和日均支出，读取所有可读角色的本月钱包流水计算；任一角色流水不可用时显示“—”，避免用部分流水冒充全量速度。
- 顶部对成功读取的余额使用十进制整数运算精确相加，支持科学计数法、大额与负值，不经浮点数相加。全部成功时显示“全部角色合计”；有缺失、失败或未授权角色时改为“已读取余额合计”并显示已读取数量，不能把部分合计冒充全部资产。无成功快照显示“—”，真实零余额显示 0.00；失败行可单独重试。
- 仅当前站点管理员且拥有来源管理范围时显示首页审批待办：待审批、待发放、异常、待补充四类，统计使用审批中心授权后的全量计数；列表只预览当前分类最早五条，点击进入原审批详情。非站点管理员不请求首页管理队列；管理员身份也不替代后端原审批范围。
- 常用入口按启用模块过滤；审批、兑换关闭时不读取对应数据。系统模块独立诊断部署保留运行信息页。工作台不再使用“暂无军团数据”“游戏数据未接入”等早期占位内容。
- 复用原模块公开 API 与账号隔离的 Query 缓存；不新增统计表、迁移、ESI 请求或业务写操作。审批、兑换、PAP 每 30 秒前台刷新；钱包范围与本人各可读角色的本地余额快照每 60 秒刷新，复用钱包页面缓存。不为未知授权角色发送余额请求。钱包范围或角色列表失效时隐藏旧对象；单角色失败从本轮合计排除并明确标记。完整列表与流程仍在业务页面，工作台不重复审核表单。
- 请求失败保留恢复操作；审批来源部分不可用时隐藏完整数量并显示“—”，不能把未知当成零。最近兑换仅表示第一页中最新五条，不能用于推算全部待办数量。余额保留实际负值。

### 布局与交互

- PAP 来源分离本轮验证：构建、lint、86 项前端单测通过；工作台读取联盟 PAP 快照，考勤页继续分别展示联盟与军团 PAP。联盟快照导入和真实达标闭环沿用联盟 PAP 同步服务。

- 审批区占满内容宽度，四个可切换统计项；700px 以下改两列。当前选择使用边框与 `aria-pressed` 表达，图标配短名称。
- 角色、果壳币、PAP、个人钱包宽屏按两列等宽排列；Grid 同排拉伸到该排内容所需高度，果壳币与角色卡底部对齐，不设固定高度或裁切。700px 以下单列并按内容自然增高。角色在卡内两列，380px 以下单列；统计附属信息靠底对齐。
- 常用入口按可用宽度自动排列，手机两列。最近兑换使用对齐行，手机重排为两列信息；待办和订单最多五条，避免首页无限增长。
- 中英文词表、日期/数字本地化、44px 操作区与键盘焦点遵循[通用规范](../ui-design-rules.md)。UI/UX Pro Max 两次 React 检索未命中；本轮使用其已读的可访问性/响应式检查表和项目规范，不引入新的设计系统。
- 浏览器验收使用模拟接口：管理员/普通成员、停用兑换/PAP/钱包模块、部分失败、空列表、同排卡片等高、PAP 本人范围、全部角色钱包展示与合计、零余额与无快照，以及中英文 320/375/768/1440px；截图保存在 `docs/ui/reviews/workspace/`。精确合计另有单测覆盖超出 Number 精度的大额、科学计数法、负值及缺失。真实业务写操作不属于本轮验证。

## 系统状态页面要求

- 展示平台服务、数据库、游戏数据状态，保留刷新操作与错误重试。
- 不增加虚构统计；系统状态继续独立于业务工作台。
- 系统页展示服务版本、数据结构版本和最近检查时间。
- 启用 EVE 登录时，首页 `/` 先检查本站会话：未登录以 replace 跳转 `/login`，已登录显示工作台；检查期间不加载工作台数据，失败显示短错误与重试。仅 system 模块的诊断部署保留首页，不跳向不存在的登录页。此规则不改变 `/system` 的当前入口或后端对象权限。

## 当前实现参数

- 三项概览采用横向内容组合；桌面内边距 24px、状态值 18px，手机状态值 16px，窄屏改为单列。
- 运行信息、空状态卡最大宽度 640px；空状态外壳承担唯一一层上下内边距。
- 当前参数只记录现有方案，不强制其他页面复制同一布局。

## 管理员导航扩展（2026-09-14）

新增“成员”入口后，小屏导航按三列自动换行，保留图标与短名称、44px 操作区域及自然键盘顺序，避免多个已交付模块挤出视口。成员入口仅对当前站点管理员显示。

### 工作台 PAP 与钱包视觉调整（2026-09-22，已发布）

- 月度目标复用考勤配置接口，不硬编码 3 分。环形进度最大填满一圈，中心显示实际总分；达到目标显示“达标”，未达到显示剩余 PAP。要求读取失败保留已读总分并提供重试，不绘制虚假达标图；无快照不显示 0。移除与本人积分无关的上游全局同步记录数。
- PAP 与钱包仍同排等高。PAP 图与月度目标横向排布，下方最多三条角色积分；钱包使用大号合计、平铺收支、最多三条头像明细。较窄卡片中钱包金额移到角色名下一行，保持数字完整。
- 共享环形图样式归图表组件，工作台不依赖先进入考勤页加载样式。

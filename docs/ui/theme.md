# 界面主题

2026-10-23 用户要求增加暗色模式，覆盖旧“仅浅色”范围限制。继续使用 Corporate Clean 的蓝色品牌、圆角、信息密度及动效；不使用滤镜反色，不更改业务流程。

## 使用

公开首页及工作台顶栏在语言入口之前提供 44px 主题图标。点击后选择“跟随系统、浅色、暗色”，选中项带勾选；图标分别为显示器、太阳、月亮，菜单支持键盘、Escape 和焦点返回，中英文一致。

默认跟随系统的 `prefers-color-scheme`，系统切换时立即更新。显式选择浅色或暗色后不再随系统变化，直到重新选择跟随系统。偏好以 `glorynavy.theme` 保存于当前浏览器，同源标签页同步；不关联本站账号、不写服务端。存储不可用时当页仍可切换，下次加载恢复跟随系统；无效保存值按跟随系统处理。

切换不刷新页面，保留筛选、滚动、弹窗、表单草稿和账号状态。入口使用统一 Select，浮层与弹窗继承主题；主题切换不是业务权限或后台配置。

## 实现约定

- `web/public/theme-init.js` 在页面样式和 React 之前设置根节点 `data-theme` 与 `color-scheme`，避免已选择暗色时先绘制浅色。公开预渲染文档与成员应用壳共用此脚本，无内联用户数据。
- `web/src/lib/theme.ts` 维护内存偏好、系统及跨标签事件；`useSyncExternalStore` 为预渲染提供固定服务端快照，避免主题差异产生水合错误。
- `web/src/theme.css` 统一定义成对背景、卡片、文字、边框和业务状态语义变量；各模块引用变量。Tailwind 的 dark 变体由 `data-theme` 控制，不能绕过用户显式选择而按系统主题独立生效。
- 暗色使用深蓝灰背景及卡片、浅色正文和提升对比度的语义状态色。主按钮使用浅蓝背景及深色文字；危险按钮保留实心深红及白字。占位符使用可读的辅助文字色。业务状态同时保留文字或图标，不只依赖颜色。
- 四类 ECharts 组件订阅实际主题，在切换后重建并读取共享变量；图表数据与请求逻辑不变。固定素材不反色。
- 公开首页的深空页头、首尾和特色 PVP 卡保留固定品牌色，介绍、活动、成员保障的内容区与卡片随主题变化。首页布局及滚动行为保持原实现。

无后端、API、权限、迁移或新增依赖。版本与本轮验证见[项目状态](../project-status.md)及[交付记录](../history/dark-mode-20261023.md)。

- **字体**：沿用 Segoe UI/微软雅黑等既有字体栈；大品牌标题和简短副标题保持方案层级，正文 14–15px。英文自然换行；手机版牌标题未裁切。没有照抄概念图上的小字装饰。
- **布局**：深色首屏、浅色双栏中段、深色招募底部的顺序保留；真实舰船比例不同，改为左文右船。手机单列、图在文字后，页头入口保持可操作。320/375/768/1440px 无横向溢出。
- **颜色**：蓝色主操作沿用项目色；首屏、近景和底部使用同一张暖金深空，白色正文区不受背景主题影响。背景右侧亮光避开左侧主要文案。
- **素材**：真实透明 PNG 与官方来源参考 SHA256 完全一致，1400×980，未重绘或拉伸；星空单独生成，所有图片已实际加载。近景允许按框裁切，不伪称为新拍摄角度。
- **内容与状态**：仅公开军团介绍、招募联系方式及登录入口，不展示成员数据或虚构人数。复制后显示“已复制群号”；失败保留可手工复制文本。KOOK 使用用户给定地址，未替用户加入。语言切换、登录 POST、会话失败仍可读首页、工作台入口均覆盖。

# 全站排版检查 · 2026-09-20

状态：本地前端已构建，未发布生产。沿用 [Corporate Clean 规范](../ui-design-rules.md)，本轮不修改权限、发放规则、ESI 同步或数据库。

## 范围与目标

检查页面层级、卡片密度、标题/工具栏、长名称、完整数值、窄屏重排和公共弹窗。使用当前本地管理员会话与已有数据；未新增奖励、修改配置、提交申请或执行交付。UI/UX Pro Max 仅补充长文本重排、焦点与点击区域；不重新选择视觉风格。

既有白底蓝色主题、Lucide、共享 Select/Modal 和表格边界继续保留。大表格允许在自身容器内横向滚动，不把整页裁切来掩盖溢出。

本次是排版与交互检查，不等于完整 WCAG 审计。当前登录状态访问 `/login` 会跳转账号页，因此登录页本轮仅核查源码与既有布局规则；未退出用户会话进行 SSO 测试。未覆盖所有异常响应、所有业务弹窗和任意长度用户输入；没有跨浏览器复测已暂停的 Edge 卡顿问题。生产仍保持原版本。

### 新发现与修复

- 长错误消息可能撑开考勤、配装、技能、权限等区域：共享 `role=alert` 支持任意位置换行，保留消息内容。
- 考勤长错误使重试按钮垂直居中漂在大段文字旁：改为顶部对齐、紧凑间距，保留固定点击区域。
- 奖励库连续英文名称可撑出卡片：在标题所在 flex 项内允许收缩与换行；加载失败补上重试。
- SSO 图片慢响应时按钮可能成为空黑块：图片完成前显示可见登录文字，失败仍可操作。
- 旧回归仍引用扁平菜单、原生 select、旧合同状态译名及旧成长/奖励表单：同步为当前交互，不把已取消的字段重新加回页面。

# 建筑管理页面

页面路径：`/structures`。页面按 Corporate Clean 规则使用卡片网格，默认中文并通过 `msg` 维护固定文案。

状态 `shield_vulnerable` 在卡片与提示中显示为“可攻击（护盾）”，英文显示为 “Vulnerable (shield)”；接口保留原始 ESI 枚举。

- 顶部显示建筑管理标题和刷新按钮；分类工具栏使用紧凑下拉筛选，按接口返回的实际建筑类型（如空堡、铁壁、阿塔诺、POS 控制塔）显示数量，避免顶部按钮堆叠。
- 内容按军团分组，每组显示军团名称、军团 ID、建筑数量和最近同步时间；组内使用固定宽度范围的自适应卡片列，避免少量建筑时卡片被拉成长条；窄屏单列。
- 每个建筑类型在军团内单独成组，类型标题与卡片放在同一浅色分组容器内；卡片保持同组等高，右上角固定显示实际类型徽标和状态，星系显示在名称下方。
- 建筑卡片用高对比度燃料到期条显示时间，并按剩余时间区分正常、预警和紧急；POS 时间由最近快照的控制塔燃料消耗计算；不在首屏展示建筑 ID。
- 页面在顶部汇总燃料告警数量，并提供“只看告警”快速筛选；POS 燃料明细使用 SDE 名称显示物品，服务列表使用原生可键盘操作的渐进展开。
- 首次加载、刷新失败、没有授权数据和窄屏布局均有状态反馈。
- 页面不提供租用、ACL/Profile 修改或 POS 权限写入入口。

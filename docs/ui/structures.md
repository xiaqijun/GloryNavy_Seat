# 建筑管理页面

页面路径：`/structures`。页面按 Corporate Clean 规则使用卡片网格，默认中文并通过 `msg` 维护固定文案。

- 顶部显示建筑管理标题和刷新按钮；分类工具栏按接口返回的实际建筑类型（如空堡、铁壁、阿塔诺、POS 控制塔）提供筛选，并显示每类数量。
- 内容按军团分组，每组显示军团名称、军团 ID、建筑数量和最近同步时间；组内使用两列自适应卡片，窄屏单列。
- 每个建筑类型在军团内单独成组；卡片右上角固定显示实际类型徽标和状态，星系显示在名称下方。
- Upwell 卡片用高对比度燃料到期条显示时间，并按剩余时间区分正常、预警和紧急；不在首屏展示建筑 ID。
- POS 燃料明细和服务列表使用原生可键盘操作的渐进展开，避免每张卡片堆叠长文本。
- 首次加载、刷新失败、没有授权数据和窄屏布局均有状态反馈。
- 页面不提供租用、ACL/Profile 修改或 POS 权限写入入口。

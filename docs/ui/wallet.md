# 钱包页面

2026-09-25 已发布：选定钱包后的流水和交易页签在当前页可读时预读另一页签首屏；有下一页游标的记录只预读下一页。筛选、角色和分部各自使用独立缓存，不跨范围显示旧记录。

2026-09-20：流水中英文改用官方 SDE 名称（ESS 为“事件监测装置保证金支付”），原始类型与备注继续保留；关联对象来源及两个英文技术回退见[术语指南](../integrations/eve-terminology.zh-CN.md)。较长的流水类型使用均衡换行，避免末行只剩单字；保留手机横向表格、完整名称和原有字号。

`/wallet`，Corporate Clean 浅色主题，沿用[通用规范](../ui-design-rules.md)及 ui-ux-pro-max 的 React 稳定记录 key 指引。此页展示游戏 ISK，不与果壳币混用。

2026-09-24 本地待发布：工作台钱包卡片改用个人钱包汇总接口，一次读取当前账号所有可读角色的余额与本月收支；总额仍覆盖全部角色，列表仍只显示前三。缺少余额快照继续显示“—”和已读取数，不将缺值算 0。`/wallet` 明细页仍按选中角色/分部请求分页记录。

- 标题＋钱包归属下拉，按个人/军团分组；归属列表按权限生成，成员管理可带 `member` 和 `owner` 打开。
- 余额使用内容宽度卡片，数字、ISK 与采集时间三级信息；军团分部选择靠近余额，不铺设七张空卡片。
- 收支流水与市场交易采用两个短标签。搜索、更多筛选、查询、刷新、翻页、查看详情使用统一 44px IconAction；下拉复用 Select，详情复用 Modal。
- 流水默认展示时间、类型/简短备注、参与方、收支及余额；市场交易展示当前语言的 SDE 物品、交易对象、数量、单价与买卖方向。正负值保留符号，图标和颜色辅助识别。完整说明、备注、税额、原始 ID 在详情中读取。
- 单页 50 条；筛选在服务端执行后再分页。日期按本地自然日转换为接口时间范围；完整 ESI ref_type 保留，当前官方 162 种类型及 12 种关联对象提供中英文标签。
- 余额卡片 24px 内边距；查询栏 20px/24px；表格 12px/16px 单元格；375px/320px 页面重排、表格在有边界的区域内横向滚动，页面本身不横向溢出。
- 同对象后台刷新保留历史，切换归属、分部、记录类型重建分页与筛选，避免显示另一钱包数据；缺失金额显示“—”，异常保留重试入口。
- 不构造缺少完整历史支撑的收支趋势图，不用当前一页之和冒充完整收支统计。后续补损依据合同核查，钱包页面不出现补损匹配按钮。

行为验证使用 `web/e2e/wallet.spec.ts`，演示截图保存在 `reviews/wallet/`。演示数据不等于真实 ESI 联调；实际覆盖情况见[项目状态](../project-status.md)。

2026-09-19：接入[全站语言切换](language.md)。流水列表副行仅展示玩家 `reason`（存在时）；ESI 自动生成的 `description` 放到详情的“原始说明”，同处保留“原始类型”便于核对。名称与原始备注不机器翻译，筛选仍提交官方原始枚举。大额 ISK 字符串和大 ID 不转浮点数。

2026-09-16 验收：桌面与手机 4 项浏览器测试通过，覆盖筛选、完整详情、同钱包刷新保留记录、换钱包清理旧记录，以及 375px/320px 布局。表格滚动容器建立定位上下文，避免隐藏表头的绝对定位文本扩大手机布局视口；按 documentElement.clientWidth 检查页面溢出。窄屏查询栏采用“搜索独立一行＋方向与三个图标”排布。未触及暂停排查的 Edge 全站问题。

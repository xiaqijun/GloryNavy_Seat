# 图表适配检查（2026-09-22）

本次按“比较、占比、趋势使用图表；快照、状态和可操作列表保留文字”的原则检查已实现页面。

| 页面 | 当前展示 | 处理 |
| --- | --- | --- |
| 联盟 PAP | 当前 PAP 与月度目标 | 改为环形进度图，中心读数仍保留在旁侧，提供可访问摘要 |
| 军团 PAP | 分数、集结次数、出勤角色人次 | 保留指标带；这些是同一周期的独立快照，不引入无意义的比例图 |
| 在线时长 | 按日统计和时间范围 | 已使用共享 ECharts 柱状图 |
| ESI 令牌桶 | 多接口窗口比较 | 已使用共享 ECharts 比较图 |
| 技能训练队列 | 单项训练剩余时间 | 保留条形进度，适合查看当前任务的完成程度 |
| 钱包 | 当前余额与交易流水 | 保留金额和流水列表；缺少统一时间序列汇总，不虚构趋势 |
| 兑换中心 | 可用、占用、已兑换果壳币 | 保留指标带；三项金额需要精确读取和直接操作 |
| 审批工作台 | 按类型待办数量 | 保留可切换分类按钮，数量本身就是导航入口 |
| 福利与损失 | 单笔核价、资格和处理状态 | 保留详情与状态，不用图表掩盖审核字段 |

环形图使用项目 ECharts 主题、SVG 渲染、品牌蓝与边框色，支持 `prefers-reduced-motion`，并提供 `aria-label` 的当前值/目标值摘要。移动端缩小绘图区但不隐藏数值。该前端适配已随 `v0.1.0-pap-chart-20260922` 发布，API、数据库和会话保持不变。

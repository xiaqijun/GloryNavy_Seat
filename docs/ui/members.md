# 管理员成员页面

新增：wallet 启用时，有效成员角色提供“查看钱包”入口，携带 member/owner。后端每次重查当前管理员、绑定、凭据游戏所有者和 scope，不扩大任何成员写操作。


2026-09-14。入口 `/members`，遵循[通用 UI 规范](../ui-design-rules.md)与 Corporate Clean；ui-ux-pro-max 补充键盘、焦点和小屏检查。

## 内容与操作

仅当前站点管理员显示成员导航；无权限直达显示拒绝，不请求成员资料。搜索复用 25 个账号一页的成员目录，可按任一绑定角色名、角色 ID 或账号 UUID 查找。行内展示主角色头像、名称、角色数量与管理员短标记。搜索、上一页和下一页为 44px 图标操作；空、加载、失败分别呈现。

选中成员进入资料视图，URL 保留 member、character 及目录搜索分页。角色选择项等高，名称完整换行，主角色用皇冠、当前查看用勾选及浅蓝背景标识。切换查看不改变登录身份或主角色。

详情显示当前角色、军团职务、平台角色、ESI 同步状态；社区资料为独立窄卡，QQ／KOOK 上下两行，值与确认状态分别展示。暂无总部／基地／其他职务时不增加空分组，原始数据仍由接口返回。社区模块关闭时明确标识；未同步、身份异常与无职务不混作已同步。

“查看合同”进入该成员的有效角色范围，合同页提供返回成员资料入口。资料页不提供绑号、解绑、主角色更改、重新授权、社区编辑或确认按钮。管理员查看已有数据不代表能绕过 ESI 授权获取尚未同步的数据。

## 排版与状态

- 页面最大宽 1200px、区域间距 24px；目录桌面两列，1000px 以下单列。
- 角色选择项桌面最大 220px，不随少量角色无限拉宽；小屏两列，名称可换行、头像尺寸固定。
- 详情桌面为主内容加 280px 社区栏，1000px 以下纵排；社区卡最大 420px。卡片内边距 24px，小屏 20px。
- 成员资料和同步缓存键含操作者与目标 ID，切换成员不保留上一成员内容；刷新返回拒绝或失败时移除旧资料并提供恢复入口。权限定期重查，后端每次请求均独立核验。
- 新增菜单后，小屏公共导航三列换行，完整保留图标与短名称。进入成员详情聚焦角色标题，Tab 顺序与阅读顺序一致。

接口及权限见[中英文授权说明](../integrations/seat-authorization.zh-CN.md)与[合同说明](../integrations/contracts.zh-CN.md)。本页参数是页面适配，不作为新的全站通用规范。

2026-09-15：attendance 启用时，有效绑定角色区域增加“在线时长”入口，打开 `/attendance?view=online&member=...`；统计对象是该成员账号的有效绑定角色集合，沿用管理员逐次检查。模块未启用不显示入口。

技能模块启用时提供“技能管理”入口，链接 `/skills?member=<account UUID>`。仅当前站点管理员可以读取其他有效绑定成员的完整技能与训练队列，不授予游戏写入操作。

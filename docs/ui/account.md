# 我的角色：页面需求与设计记录

2026-09-16：解绑与账号合并保留原 Radix 认证流程及关闭限制，外层统一使用公共弹窗的遮罩、层级、圆角、阴影、标题与说明样式；确认框最大 440px，合并预览最大 560px，手机按视口收窄。

## 账号合并（2026-09-15）

角色列表标题行增加次要“合并账号”入口，使用现有按钮、头像和弹窗。第一步只说明验证与数据范围；SSO 返回后显示来源/目标主角色、迁入角色和 PAP/果壳币/订单摘要。明确保留目标主角色及社区资料、原账号权限不迁入、其他会话退出与不支持自助撤销。

确认按钮仅在预览有效时可用；请求中禁用重复提交，过期/变化显示行内错误，可刷新预览或取消。宽屏双列身份和数字，小屏身份纵排、操作自动换行；焦点陷阱、Escape 取消与头像后备沿用既有组件。没有添加新导航页面或更换全局风格。接口夹具桌面/375/320px 验证与真实操作范围见[项目状态](../project-status.md)。

适用范围：`/account`。本文记录页面要求和实现决策，不是通用 UI 规范；具体数值只适用于此页，可在满足需求时调整。继承[全局 UI 规范](../ui-design-rules.md)，不继承登录页的大幅品牌画面。更新：2026-09-14。

## 页面需求

- 管理同一用户的多个 EVE 角色：选择查看、添加、设为主角色、更新授权和解绑；保留完整姓名、主角色及异常标识，不常驻展示“本次登录”。
- QQ 与 KOOK 归本站账号共同使用，放在独立窄社区卡，展示和编辑均上下排列；确认状态使用“待确认／已确认／未填写”。
- `/account` 只展示和编辑账号级 QQ 号、KOOK 昵称等社区资料。站点管理员通过 `/community` 的 QQ 机器人管理页维护官方 QQ Bot 与“QQ 入群审批”配置；App Secret 使用写入字段，服务端加密保存且不回显。
- 当前角色的身份、军团与职务、ESI 授权状态共用一张详情卡；本站分配的角色单独分区，避免与游戏角色混淆。
- 保持 Corporate Clean 的品牌蓝、灰白底、细边框、圆角与轻阴影；信息密度适中，图标辅助识别和操作，必要业务信息保留文字。

## 当前设计（2026-09-14 重排）

以下是此页的实现决策，可随内容调整，不是全站固定尺寸要求。

| 区域 | 当前排法与参数 |
| --- | --- |
| 页面 | 最大 1000px；页头一个主标题，返回、退出使用图标操作。可用宽度至少 900px 时，左社区栏 300px、右角色栏自适应；不足时按 DOM 顺序纵排 |
| 社区资料 | 卡片最大 360px；标题与资料、QQ 与 KOOK 之间使用细线分组。44px 平台图标、16px 数据、12px 标签与确认状态。编辑状态保留可见字段标签，删除重复填写说明 |
| 角色选择 | 200px 统一宽度，空间不足时缩小；整组等高，由最长内容决定。40px 头像和姓名顶部对齐，12px 内边距与项间距。选中项浅蓝底、蓝边框和头像角标勾选；主角色使用轻量星标，完整长名换行 |
| 身份栏 | 浅蓝色底作为轻量装饰，64px 头像、姓名与主角色标识、次级 ID；姓名桌面 22px、窄栏 20px。操作靠近身份，栏宽不超过 520px 时另行靠右 |
| 军团与职务 | 48px 军团图标与名称一组，职务标签一组，宽栏并排、520px 及以下纵排。默认前六项，更多职务和地点职务折叠；标签内边距 4px/8px，保留完整文本 |
| 详情底部 | ESI 授权与平台角色宽栏左右分区、520px 及以下上下排列，细线分隔；标题 14px、组内间距 8px，桌面内边距 20px/24px、窄栏 16px/20px |

### 术语与状态

- 将原“本站角色”分区改为“平台角色”，指本站分配的权限角色；空状态显示“未分配角色”，不能解释为该用户没有任何权限。实际权限仍受管理员身份、军团策略等现有规则影响。
- ESI 状态保留短结果和一次同步时间；异常时保留必要原因与恢复操作，不把过期、等待和授权缺项显示为成功。
- 角色授权加载或失败时保留身份栏和仍可使用的操作；军团职务功能关闭时只显示身份内容。

## 数据与交互边界

- 头像和军团图标根据当前接口返回的角色/军团 ID 从 EVE 图片服务获取，不把所有角色固定成 Glory Navy。图片加载或失败时显示同尺寸的通用图标，避免空白与布局跳动。
- 未登录仍返回 `/login`；加载、接口失败、退出失败各有对应状态。
- 沿用已有快照新鲜度判断，失效或撤权时隐藏旧游戏职务；平台角色不与游戏职务混为一谈。刷新按钮重新读取服务端状态，不宣称强制刷新 ESI 缓存。
- 添加角色与更新授权使用受保护接口和 CSRF；更新授权锁定选中的角色，取消或选择错误角色时按需提示。
- 已实现头像角色列表、添加角色、主角色标记与选择、独立重新授权及解绑。首次进入默认查看主角色；卡片只显示主角色、选中状态及必要异常标记，不显示“本次登录”；实际登录角色仍在会话中保留，点击角色只切换查看。解绑使用可键盘操作的确认对话框；解绑当前登录角色时明确提示“本次登录也会退出。”，失败保留重试，解绑本次登录角色后返回登录页。主角色不直接提供解绑入口，后端同时保护主角色及最后一个可登录角色。多角色规则见[接入说明](../integrations/seat-multi-character.zh-CN.md)。

- 社区资料切换角色时不重置，保存成功有简短反馈；校验错误紧邻字段，提交失败保留输入。版本冲突需主动读取最新资料，不能自动覆盖；修改已确认值时提示对应平台需重新确认。未完成入群确认不显示成 OAuth 已绑定。

## 验收

检查桌面、375px 与 320px 布局、长角色名、多职务折叠、图片失败及键盘操作；重点检查过期/撤权后旧职务不显示、更新授权与退出仍可用。测试数据与截图演示不能当成真实玩家数据联调结果。

已发布 /approvals；业务、权限、接口及分页见[中文指南](../integrations/approval.zh-CN.md)。沿用[通用规范](../ui-design-rules.md)，并按 ui-ux-pro-max 补充响应式、焦点与交互反馈。

- 导航位于工作台之后，来源授权决定可见性。页面不用大统计卡；四个轻量页签及数量，待补充作为待审批筛选。
- 桌面全宽单表：类型编号、申请人、项目/舰船、金额与物品、状态、时间、查看。申请人优先主角色，接收角色不同才辅显；ISK、果壳币分别标明单位，不合计。成长/活动福利显示冻结奖励中的 ISK、果壳币及最多两项舰船或物品名称与数量，其余以项数提示；兑换单同时显示果壳币花费及冻结奖品摘要。没有金额和实物时才显示破折号，不显示假零。
- 1100px 以下隐藏项目次要列，详情仍完整；680px 以下改紧凑纵向记录，每行内部按信息分区，整页无横向滚动。页签可横向滑动，不把单据列表硬分两列。
- 搜索/业务/军团与当前视图状态优先；日期、人员及重置放“更多筛选”。日期明确 UTC 起始含、截止不含。
- 一个统一 Modal，审批与取消表单替换弹窗内容，不叠第二个模态框。失败保留理由；提交中禁止重复；关闭恢复原筛选、页码和触发焦点。
- 合同复制区只用于待发放状态；取消待审不提供新的发放操作。原审计折叠，自动完成显示系统核验。
- 已发出的合同若等待成员领取（`awaiting_acceptance`），不再计入“待发放”；它保留在“已处理”中并显示等待领取状态。
- 首版桌面/手机、中英文、Chrome/Edge 截图目录 [reviews/approval](reviews/approval/)。记录少时不拉高空卡片；空态保留明确占位。
- 会话确定后先读取权限上下文，只有获准才请求管理列表；服务端分别复核权限，不短暂展示未授权待办数据。

# 贷款页面

`/loans` 使用 Corporate Clean 财务分组。首屏展示统一池待核验入金、已入池资金、可放贷余额、系统信用评分、总责任额度、无担保额度和本人贷款列表；统一贷款池固定为单例，成员提交个人/军团出借金额并完成入金合同核验。信用评分和额度由系统按贷款履约记录自动评估，页面显示评估来源和结果，不提供人工配置入口。提交出借和提交贷款申请均通过按钮打开表单弹窗；借款申请不再选择贷款池，自动进入唯一统一池。贷款弹窗使用固定总利息、期数、间隔天数和首期到期时间，提交成功后关闭弹窗并刷新列表。金额按 ISK 显示，接口仍传整数最小单位。

贷款详情、分期、付款合同、担保和抵押审批沿用统一弹窗/详情布局，长分期和证据不塞入主列表。加载、无额度、空列表、合同不匹配和权限失败均保留可操作的错误或重试入口。桌面使用三列信用摘要，显示系统评估来源；金额表单三列，窄屏所有表单单列，表格在有边界的容器内横向滚动。表格行提供轻微悬停背景，输入框和下拉框使用白色字段底、对比边框和可见键盘焦点环；样式使用主题变量的显式回退，避免主题未提供别名时浏览器丢弃边框。已用桌面 1440/1000px 和手机 375/320px、中文/英文共 8 个实际渲染场景检查控件可见性与横向溢出。

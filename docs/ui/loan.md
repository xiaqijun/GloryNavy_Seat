# 贷款页面

2026-10-13 贷款办理页重排：顶部信用摘要统一为评分与额度两张指标卡，不再在额度为 0 时追加通用原因说明或状态标记；下方操作入口横跨内容区，贷款记录置于主列，担保邀请和出借记录置于侧列，窄屏按操作、担保、出借、贷款顺序单列显示。

看板中的“已入池资金”只统计贷款流水账本中的已确认资金，包括已完成并核验的出借入金和管理员直接登记的入池资金。管理员登记资金直接写入贷款池账本，不创建或核验游戏合同。

侧栏仍在“财务与工具”主菜单下显示“贷款”入口。`/loans/operations` 是贷款办理页，内部以“贷款看板 / 贷款办理 / 风控设置 / 评估记录”作为子页面；`/loans` 保留为兼容入口并自动跳转到“贷款看板”子页面。贷款看板只展示统一贷款池的整体借贷信息：待核验入金、已入池资金、已放款本金、已预留本金和可放贷余额；资金金额仅对管理员或可管理统一池的账号展示，普通用户只看到贷款池状态。切换分页下方的信用摘要卡片只保留当前账号的信用评分和个人额度，不展示评分因子；随后进入申请、担保、抵押与出借操作。申请和出借入口收在一个双列操作卡片中；担保邀请列表始终在下方保留，担保人直接在列表查看本金和责任额度并接受或拒绝邀请。长规则说明放在设置与表单弹窗中。借款申请不再选择贷款池，自动进入唯一统一池。抵押表单从当前账号可查看的已完成物品交换合同中选择，物品清单由后台快照读取，不能手填；担保表单从有效绑定的其他 EVE 角色中选择，后台提交时再次解析本站账号。贷款弹窗使用本金、分期期数和间隔天数，首期还款时间在实际放款后按间隔自动生成；间隔天数只能选择 1、3、7、14 或 30 天；利息由风控设置的年名义利率按 365 天固定单利计算，并在申请时冻结利率与利息快照。提交成功后关闭弹窗并刷新列表。金额按 ISK 显示，接口仍传整数最小单位。

贷款详情、分期、付款合同、担保和抵押审批沿用统一弹窗/详情布局，长分期和证据不塞入主列表。贷款设置只对贷款管理者显示，可从所有有效绑定的 EVE 角色中先选账号昵称、再选该账号的合同处理角色，不限制为当前管理账号角色；管理员可在同一处直接登记入池资金，这笔资金写入账本，不创建或核验游戏合同。出借角色和收款角色在存在多个账号时使用“昵称 → 子角色”两级选择器，单账号时只显示角色选择，提交仍使用角色 ID。合同处理人只决定出借、放款和还款合同的接收角色；可放贷余额仍只来自已核验贷款流水或管理员登记。系统禁止同一角色给自己交付合同。授信规则的每个字段标签旁提供小问号说明，桌面支持悬停和键盘聚焦，移动端点击打开可关闭的说明浮层；说明包含 bps 换算、收入/消费能力分开统计、70/30 默认权重、钱包样本计数、抵押估值基数和数据不足处理口径。资产规模评分使用当前账号有效绑定角色的个人 ESI 资产快照和全服平均价，按总估值低于 1 亿、达到 1 亿/5 亿/10 亿/50 亿/100 亿 ISK 对应 0/2/4/6/8/10 分；没有有效均价的物品跳过，其他已成功读取且有均价的个人物品继续计入，部分角色读取失败会记录在资产证据中，完全没有可估值物品时保持中性；钱包和军团资产不计入。出借记录采用紧凑列表行，只显示接口返回的出借角色名字、出借类型、金额和状态；点击列表行打开出借详情弹窗。详情弹窗显示时间、入池状态和合同状态；待核验时只提供创建合同所需的贷款专员角色名字、支付金额和合同备注复制字段，角色 ID 只用于后台校验，名称暂不可用时才回退显示 ID。合同类型与无物品要求作为说明，合同完成并同步后由系统自动核验，不提供核验按钮。贷款办理页始终显示“我的担保邀请”区域；担保人可在这里查看贷款本金和担保金额，在有邀请时直接接受或拒绝，接受后占用当前总责任额度并在贷款结清后释放。担保金额受其当前可用责任额度限制，接受时服务端重新核验，管理者可在有权限时批准抵押或提出异议。加载、无额度、空列表、合同不匹配和权限失败均保留可操作的错误或重试入口。桌面信用摘要使用双列，仅显示信用评分和个人额度；整体借贷信息使用五列金额指标，金额表单三列，窄屏所有表单单列，列表在有边界的容器内保持无横向溢出。列表行提供轻微悬停背景和可见键盘焦点环；样式使用主题变量的显式回退，避免主题未提供别名时浏览器丢弃边框。桌面和 375/320px 窄屏均检查列表、弹窗、复制字段和错误信息的可见性。
2026-10-14 算法与抵押交互：贷款办理页只读取最近一次周期性信用快照，后台每 24 小时评估一次；超过默认 72 小时的快照不能用于新增担保、抵押审批或贷款审批。信用摘要继续只显示信用评分和个人额度。风控设置新增个人资产授信比例（默认 10%），收入 70% / 消费 30% 继续按权重合成基础额度。抵押弹窗移除估值和折扣输入，显示后台按已完成合同物品快照和 ESI 均价自动估值的说明；组装船只按父子物品合计，缺价整笔拒绝。

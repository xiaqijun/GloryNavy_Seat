# 贷款页面

`/loans` 使用 Corporate Clean 财务分组。首屏展示统一池待核验入金、已入池资金、可放贷余额、系统信用评分、总责任额度、无担保额度和本人贷款列表；统一贷款池固定为单例，成员提交个人/军团出借金额并完成入金合同核验。信用评分和额度由 system-v2 自动评估：履约 55、负债压力 20、担保/抵押履历 10、PAP 5、资产规模 10；授权状态和账号持续时间不展示为评分因子。提交出借、提交贷款、邀请担保和登记抵押均通过按钮打开表单弹窗；出借与申请按钮共用一个无卡片操作栏，不再各占一张独立卡片。借款申请不再选择贷款池，自动进入唯一统一池。抵押表单只提交完成合同信息，物品清单由后台快照读取，不能手填。贷款弹窗使用固定总利息、期数、间隔天数和首期到期时间，提交成功后关闭弹窗并刷新列表。金额按 ISK 显示，接口仍传整数最小单位。

贷款详情、分期、付款合同、担保和抵押审批沿用统一弹窗/详情布局，长分期和证据不塞入主列表。贷款详情显示担保/抵押状态；收到担保邀请的成员可直接接受或拒绝，管理者可在有权限时批准抵押或提出异议。出借待核验记录使用与审批中心一致的字段复制布局：合同类型、出借角色、金额、收款方、物品和合同备注分别显示为只读字段，各字段旁提供独立复制按钮和复制成功/失败状态；合同备注在桌面跨两列，窄屏自动单列。加载、无额度、空列表、合同不匹配和权限失败均保留可操作的错误或重试入口。桌面使用三列信用摘要，显示系统评估来源；金额表单三列，窄屏所有表单单列，表格在有边界的容器内横向滚动。表格行提供轻微悬停背景，输入框和下拉框使用白色字段底、对比边框和可见键盘焦点环；样式使用主题变量的显式回退，避免主题未提供别名时浏览器丢弃边框。已用桌面 1440/1000px 和手机 375/320px、中文/英文共 8 个实际渲染场景检查控件可见性与横向溢出。

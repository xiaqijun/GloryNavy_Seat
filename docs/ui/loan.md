# 贷款页面

`/loans` 使用 Corporate Clean 财务分组。首期首屏展示信用评分、总责任额度、无担保额度、开放贷款池和本人贷款列表；站点管理员在同页“贷款配置”区域创建个人/军团贷款池并设置当前账号授信。申请表使用固定总利息、期数、间隔天数和首期到期时间。金额按 ISK 显示，接口仍传整数最小单位。

贷款详情、分期、付款合同、担保和抵押审批沿用统一弹窗/详情布局，长分期和证据不塞入主列表。加载、无额度、空列表、合同不匹配和权限失败均保留可操作的错误或重试入口。桌面使用三列信用摘要；普通申请表三列，管理员配置区两列并在中等宽度降为单列，窄屏所有表单单列，表格在有边界的容器内横向滚动。表格行提供轻微悬停背景，输入框和下拉框使用白色字段底、对比边框和可见键盘焦点环；样式使用主题变量的显式回退，避免主题未提供别名时浏览器丢弃边框。已用桌面 1440/1000px 和手机 375/320px、中文/英文共 8 个实际渲染场景检查控件可见性与横向溢出。

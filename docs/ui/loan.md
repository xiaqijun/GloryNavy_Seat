# 贷款页面

`/loans` 使用 Corporate Clean 财务分组。首屏展示统一池待核验入金、已入池资金、可放贷余额、系统信用评分、总责任额度、无担保额度和本人贷款列表；统一贷款池固定为单例，成员提交个人/军团出借金额并完成入金合同核验。信用评分和额度由 system-v2 自动评估：履约 55、负债压力 20、担保/抵押履历 10、PAP 5、资产规模 10；授权状态和账号持续时间不展示为评分因子。提交出借、提交贷款、邀请担保和登记抵押均通过按钮打开表单弹窗；出借与申请按钮共用一个无卡片操作栏，不再各占一张独立卡片。借款申请不再选择贷款池，自动进入唯一统一池。抵押表单只提交完成合同信息，物品清单由后台快照读取，不能手填。贷款弹窗使用固定总利息、期数、间隔天数和首期到期时间，提交成功后关闭弹窗并刷新列表。金额按 ISK 显示，接口仍传整数最小单位。

贷款详情、分期、付款合同、担保和抵押审批沿用统一弹窗/详情布局，长分期和证据不塞入主列表。出借记录采用紧凑列表行，只显示出借角色、出借类型、金额和状态；点击列表行打开出借详情弹窗。详情弹窗显示时间、入池状态和合同状态；待核验时只提供创建合同所需的托管对象 ID、支付金额和合同备注复制字段，合同类型与无物品要求作为说明，手动合同 ID 核验放在折叠区域。收到担保邀请的成员可直接接受或拒绝，管理者可在有权限时批准抵押或提出异议。加载、无额度、空列表、合同不匹配和权限失败均保留可操作的错误或重试入口。桌面使用三列信用摘要，显示系统评估来源；金额表单三列，窄屏所有表单单列，列表在有边界的容器内保持无横向溢出。列表行提供轻微悬停背景和可见键盘焦点环；样式使用主题变量的显式回退，避免主题未提供别名时浏览器丢弃边框。桌面和 375/320px 窄屏均检查列表、弹窗、复制字段和错误信息的可见性。

# 意见反馈页面

入口 `/feedback` 为登录后的独立导航项，复用工作台、Corporate Clean 与统一中英文词表。一个主标题与“提交反馈”按钮；工具栏仅放范围（管理员）、类型、状态、刷新。列表采用整行对齐的类型、标题/作者/时间、状态，不放重复说明或统计空卡片。

宽屏行布局为 110px 类型列、可伸缩标题列与状态列，24px 水平内边距；700px 以下类型和状态同排、标题与元数据下一排，内边距 16px。列表使用全部可用主内容宽度；筛选自然换行，按钮操作区至少 44px。标题与连续长文本完整换行。

提交和详情使用共享 Modal。提交只包含类型、标题、详细描述，BUG 提示页面/操作/问题，功能提示期望功能。详情先显示原文与状态，再按时间展示回复/状态事件，底部补充或管理员处理表单。普通用户没有全量范围和处理状态控件；服务端仍独立鉴权。

按 ID 稳定分页，每页 30 条；详情链接 `?ticket=<id>`。查询键包含账号/筛选，关闭详情回到列表。提交成功打开新记录；写请求使用 UUID 防重，冲突/错误保留输入、可刷新重试。加载、空、失败和权限拒绝各有明确状态。文本不解析 HTML，不将用户标题作为 HTML 属性执行。

验收覆盖中英文、1280/375/320px 的提交、补充、管理员处理和版本冲突；截图与结果按[项目状态](../project-status.md)记录。

# 舰船配置页

2026-09-20：配装与出勤共用客户端槽位术语；统一铁骑舰载机挂舱、无人机挂舱、货柜舱及高/中/低能量槽，不改游戏物品标志或 EFT 内容。[来源与维护](../integrations/eve-terminology.zh-CN.md)。

2026-09-16：导入、替换和保存到游戏使用公共 `Modal`，统一标题、遮罩、外层与关闭/焦点行为；生成或编辑技能方案继续复用 `PlanEditor`，长清单保留固定标题和提交区。删除军团配置使用站内 `ConfirmDialog`，保留待删除条目的 ID/版本，取消不发送删除，失败可在弹窗内重试，替代浏览器原生确认框。

2026-09-15：改为军团方案库与个人游戏方案浏览。本记录替代先前模拟工作区；[同类项目调研](../history/fittings-research-2026-09-15.md)保留为历史参考。

沿用 [Corporate Clean](../ui-design-rules.md) 及 ui-ux-pro-max 的响应式、可访问性和状态要求。入口 `/fittings`；成员页链接保留管理员只读个人方案。

- 顶栏：一个标题、刷新图标、管理员导入按钮。军团/个人切换独立，当前军团或角色使用统一 Select。
- 桌面左侧 300px 方案列表，右侧详情。列表有名称/船型搜索、军团方案分类筛选、舰船图标；详情有舰船图、名称、简短说明和分槽位装备。卡片内边距 24px、区块间隔 24px，不撑空槽位和模拟属性。
- 760px 以下列表和详情切换，有明确返回按钮；320/375px 保留操作换行，装备按单列阅读。图像失败用同尺寸图标兜底，不留破损图片。
- 主要操作为“保存到个人配置”，弹窗明确“保存到游戏”并选择本人角色；旧授权显示重新授权链接。成功、确定失败、发送中、结果不确定分别反馈，不让刷新伪装游戏保存成功。
- 管理员可 EFT 导入、替换、删除；导出为图标按钮。删除确认，版本冲突保留输入，提交期间禁用重复点击。
- 有技能管理权限显示“创建技能方案”：预填最低前置技能，复用等级/增删编辑器。保存后提供编辑与跳转技能管理入口。没有自动写游戏训练队列。
- 模拟编辑、环形槽位、属性面板不再提供。历史草稿仍保留数据及兼容接口，当前 UI 不显示编辑入口。

共享 Select 弹层为 90，位于当前业务弹窗 80/81 之上，确保弹窗内等级和角色选择可点击；风格未变化。按钮/图标具备中文可访问名称和键盘焦点，保留 reduced-motion。

本轮浏览器夹具检查覆盖导入/替换/删除、成员保存、缺 scope、未知结果、技能生成/修改、桌面与手机无横向溢出；截图在 `web/.local/library-review/`，测试拦截 CDN 用于检查图像后备状态。真实 ESI 写入仍需本人重新授权后手动联调。[接入与升级](../integrations/fittings.zh-CN.md)。

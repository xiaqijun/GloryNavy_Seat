表格是完整目录，实际入口先按启用模块和当前账号权限过滤。普通成员不显示管理员入口；审批中心仅向有可管理来源的账号展示。模块停用或权限不足后的空组隐藏，分组不扩大军团或成员数据范围，不改变后端鉴权。QQ 机器人管理入口仍仅供站点管理员配置，不意味着机器人已启用。我的角色保留在右上角账号入口，不复制到侧栏。

每个页面在模块声明中配置 `navigationGroup` 和 `navigationOrder`，不再依赖模块导入顺序。未分组页面在顶部直达；`navigationFooter: true` 的页面在底部直达。新增入口仍使用统一注册表，不另建路由副本。

桌面侧栏保持 236px（761–1100px 为 208px），独立滚动；顶部间距 24px、入口间距 4px、可点击高度至少 44px。底部反馈以分隔线区分，在空间充足时贴近侧栏底部。分组最多展开一个，默认展开当前页所属组；手动收起在当前路由保留，切换路径或前进/后退重新定位目标组。权限异步返回时，未手动操作则自动展开当前组。

760px 及以下使用“菜单”按钮，默认收起，选页后收起；Esc 关闭并将焦点还给按钮。分组 button 保留 `aria-expanded` / `aria-controls`，当前页保留 `aria-current`；折叠项不进入键盘序列。固定标签提供中英文，不增加说明小字。保留页面跳转后的正文焦点和可见页面代码预热。

验证使用模拟账号和模块目录，覆盖管理员、普通成员、可审批专员及停用模块，中英文 1280/375/320px，检查排序、键盘、当前页、历史导航、手机关闭和横向溢出；测试数据不代表生产业务审批验收。具体本轮结果见项目状态。

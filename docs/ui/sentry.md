# 预警平台密钥页面

`/sentry` 使用 Corporate Clean 后台布局，每个本站账号只显示一张当前密钥卡片。首次打开自动准备密钥，不提供新建、用途分类或成员删除入口。

## 卡片布局（2026-09-30，已发布）

- 只保留密钥卡片一层边框，移除外层装饰框和内部重复分区边框；桌面宽度 280–320px，默认正方形。错误等长内容允许撑高。
- 顶部显示密钥图标、名称和创建时间，刷新图标按钮位于卡片内右上角。
- 中部显示生成或刷新后返回的完整明文，长密钥换行，不截断；点击密钥区域即可复制。没有当前页面明文时显示掩码并提示先生成或刷新。底部左侧显示状态，右侧保留复制按钮。
- 操作复用公共 IconAction，点击区域为 44px；处理中锁定刷新。移动端单列，卡片不超出可用宽度。

刷新直接轮换密钥，无确认弹窗。完整明文仅保留在生成或刷新后的当前页面内存，生成或刷新成功后直接显示；复制按钮和密钥区域复制完整明文。重新打开页面后没有明文时显示掩码并通过通知提示需要先生成或刷新，不会自动轮换或尝试恢复旧明文。

文案通过 `msg` 同步中英文，时间使用 `getLocale()`。当前本页只负责密钥生命周期；生产版本以 `../project-status.md` 为准。

## 预警消费区域（2026-10-01，第一期只读账单已实现）

密钥卡片之后增加独立的果壳币消费区域。首行显示“可用果壳币”“预警暂占”“预警累计净消费”“预警已释放”“预警累计退款”，数值统一最多两位小数。不把后台授权秒数称为余额或总额度。桌面指标按可用宽度自适应排列，手机按两列再单列紧凑排列，不收窄整页主列表。

下方记录列表按时间倒序、游标翻页，提供时间范围和状态筛选。预警区间记录优先显示发生时间、有效预警时长、对应果壳币与“暂占/已结算/已释放/已退款”；未用授权余额释放单列为“未使用金额退回”，不标成一次消费。展开后显示 UTC 起止、授权时冻结的每单位时长单价、价格版本与到期时间。区间 ID、授权 ID 用于复制和申诉定位，放在详情中。对账异常时显示记录的最近同步时间和明确状态，不把“尚未同步”显示成零消费。客户端 ACK、事件/星系及退款依据须等本地证据镜像完成后再展示，不以本地结算状态冒充 ACK 证明。

`/exchange` 币流水增加“预警暂占”“预警释放”“预警退款”标签，并能跳转到本页的相关账目；预警区间结算不新增第二条负币流水。成员仅查看本人；管理员跨成员的视图待服务端目标鉴权完成后实现。空态、读取失败、收费关闭、有历史记录和退款后余额变化均需验收。完整数据契约与发布顺序见[接入方案](../plans/eve-sentry-integration.zh-CN.md#预警消费展示方案2026-10-01第一期只读账单已实现)。

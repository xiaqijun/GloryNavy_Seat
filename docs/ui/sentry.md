# 预警平台密钥页面

`/sentry` 使用 Corporate Clean 后台布局，主内容展示果壳币消费概览和记录筛选，客户端密钥操作收进消费标题行右侧；窄屏时操作区换到标题下方。密钥区域只保留“复制密钥”和“更新密钥”两个操作按钮，不展示名称、时间、状态或明文。

## 密钥操作布局（2026-10-02，已发布）

- 客户端密钥不再使用密钥卡片、状态、时间或明文展示；两个按钮直接位于消费标题行右侧，和消费记录刷新按钮处于同一操作区。窄屏将操作区放到标题下方并右对齐。
- 复制按钮使用当前页面内存中的完整密钥；重新打开页面后没有明文时通过通知提示先更新，不把服务端哈希伪装成可复制密钥。
- 更新按钮直接执行密钥轮换，无确认弹窗；处理中锁定按钮。两个按钮均使用公共 Button，点击区域至少 44px。

文案通过 `msg` 同步中英文，时间使用 `getLocale()`。当前本页只负责密钥生命周期；生产版本以 `../project-status.md` 为准。

## 预警消费区域（2026-10-01，第一期只读账单已实现）

页面直接展示独立的果壳币消费区域。首行显示“可用果壳币”“预警暂占”“预警累计净消费”“预警已释放”“预警累计退款”，数值统一最多两位小数。不把后台授权秒数称为余额或总额度。消费标题行右侧集中放置密钥复制、更新和消费记录刷新操作；桌面指标按可用宽度自适应排列，手机按两列再单列紧凑排列，不收窄整页主列表。

下方记录列表按时间倒序、游标翻页，提供时间范围和状态筛选。预警区间记录优先显示发生时间、有效预警时长、对应果壳币与“暂占/已结算/已释放/已退款”；未用授权余额释放单列为“未使用金额退回”，不标成一次消费。展开后显示 UTC 起止、授权时冻结的每单位时长单价、价格版本与到期时间。区间 ID、授权 ID 用于复制和申诉定位，放在详情中。对账异常时显示记录的最近同步时间和明确状态，不把“尚未同步”显示成零消费。客户端 ACK、事件/星系及退款依据须等本地证据镜像完成后再展示，不以本地结算状态冒充 ACK 证明。

空消费账单的 API 响应固定返回 `items: []`、空字符串 `next_cursor` 和采集时间，页面据此显示空态，不把合法的无记录响应当作格式错误。

## 预警收费配置（2026-10-03，本地待发布）

消费区域下方显示当前预警计价规则。管理员可点击“配置收费”编辑价格版本、计价单位秒数、每单位果壳币价格、单次授权上限和授权有效期；保存使用版本号防止覆盖其他管理员的更新，并在服务端记录前后快照审计。普通成员只读查看规则。尚未保存独立规则时，页面显示部署环境提供的启动值；收费开关仍由 `SENTRY_ALERT_CONSUMPTION_ENABLED` 控制，页面不负责启停收费。新授权读取当前规则并冻结其计价快照，已有授权和消费记录不因后续改价而重算。价格金额始终按果壳币最小单位保存，时间只用于说明计价依据。

`/exchange` 币流水增加“预警暂占”“预警释放”“预警退款”标签，并能跳转到本页的相关账目；预警区间结算不新增第二条负币流水。成员仅查看本人；管理员跨成员的视图待服务端目标鉴权完成后实现。空态、读取失败、收费关闭、有历史记录和退款后余额变化均需验收。完整数据契约与发布顺序见[接入方案](../plans/eve-sentry-integration.zh-CN.md#预警消费展示方案2026-10-01第一期只读账单已实现)。

# 预警平台页面

`/sentry` 在同一个消费区域展示可用果壳币、预警价格、监控奖励价格和累计花费/奖励。价格单位为果壳币/小时，金额按服务端确认的在线秒数结算。收费开关和两个小时价格由管理员在配置弹窗编辑，普通成员只读。

标题行右侧只保留复制密钥、更新密钥、配置收费和刷新记录操作。收费状态使用图标表达；页面不展示统计时间、授权额度、授权有效期、计价详情或事件/投递/ACK 状态。密钥不会自动轮换，密钥列表加载后即可复制，更新按钮只在用户主动操作时更换密钥。

预警消费和监控奖励合并到同一星系的连续、重叠或不超过 300 秒有效采样短间隔时间流水卡片，扣费显示负号、奖励显示正号，并在同一卡片显示各自状态。流水按星系携带稳定 `system_id`，展示层会跨客户端重连和旧 `legacy:` 标识合并区间；超过 300 秒的真实断档仍分开。原始证据和币账不合并改写。余额和币账仍按本站账号归集。每个星系独立计量：主节点在线一小时产生一小时奖励，预警选择 N 个星系在线一小时消耗 N 个星系小时。

奖励累计金额直接显示在消费统计指标中，不再增加单独的奖励说明卡片。下面的流水列表只展示最近一页记录并按星系合并；累计金额与顶部账号账本的“监控奖励”一致，不能用当前页面可见的少量卡片金额代替全量累计。

接口与发布状态以 [`docs/integrations/sentry-keys.zh-CN.md`](../integrations/sentry-keys.zh-CN.md) 和 [`docs/project-status.md`](../project-status.md) 为准。

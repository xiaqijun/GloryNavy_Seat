## PAP 页面重排（2026-09-22，联盟子页与差量快照）

PAP 页面使用统一的“集结分”页头，军团 PAP 和联盟 PAP 分为独立子页：军团页只展示活动点名产生的分数，联盟页通过 `?view=alliance-pap` 集中显示本月总分、每人目标、环形进度图、达标状态和已映射角色明细。管理员可在联盟页打开月度兑换预览。角色明细在桌面使用两列紧凑列表，小屏自动回到单列，角色名允许换行，分值保持右对齐。同步中、无数据和失败状态分别显示，不以零值替代错误。联盟同步从完整上游快照开始，服务器仅差量更新本月变化行，并在成功完整读取后清理已消失角色。

“统一发放”入口位于军团 PAP 筛选栏右侧，仅在存在待处理活动时显示管理员按钮；弹窗列出已结束、有有效出勤角色且未发放的活动，可逐场调整分值并使用同一发分说明批量提交。提交结果按活动显示，成功项保留，失败项可刷新重试；不改变活动详情中的单场操作或成员视图。

军团页保留紧凑的筛选、统计和活动列表；联盟页使用同一张白卡承载总分、目标和明细，减少重复卡片与大块留白。导航 tab 使用 URL 状态，刷新或直接打开子页不会丢失当前来源。桌面与 Pixel 7 已用接口夹具检查。

## PAP 来源与要求配置（2026-09-22）

军团考勤页将活动点名所得标为“军团 PAP”，页签作为唯一页级标识，筛选栏承载范围、周期和管理员统一发放操作，主体只保留统计与明细，不附加月度达标图。联盟 PAP 要求单独显示，默认每人每月 3 PAP，并在卡片内列出已映射本站账号的角色、各自 PAP、角色数量和最近同步时间；未完成同步时不显示军团分数的达标/差额，也不伪造联盟进度。

联盟分页显示每人每月最低要求，默认 3 PAP。当前站点管理员显示配置图标，复用统一表单弹窗，只输入联盟最低分；自然人按本站账号所有角色合并计算。军团总分、近 30 天和未完成同步均不套用联盟月要求。保存校验版本，更新同账号缓存。规则失败提供重试，不显示假默认值。

## 集结分适配（Goose 24）

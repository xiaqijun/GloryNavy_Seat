# 使用帮助

2026-10-20 新增，发布状态见[项目状态](../project-status.md)，使用内容见[成员指南](../user-guide.zh-CN.md)。

## 入口与内容

- `/help` 注册在必需的 system 前端模块，侧栏底部“意见反馈”之后为“使用帮助”。复用宿主会话、目录和页面加载，不新增业务 API、权限或迁移。
- 四组、17 个主题：入门、日常使用、业务办理、专员与管理。普通成员可查阅所有说明；业务链接进入原页面，实际操作继续由原业务权限和军团范围控制，阅读说明不授予管理能力。匿名访问回到公开首页。
- 每次展示一个主题，包含简短概述、业务入口、操作步骤、必要提示或常见问题。说明采用当前规则，不承诺固定福利金额，不把游戏同步视为即时，不把已停用的 QQ 机器人列为入门要求。
- 搜索标题、概述、步骤、提示及问答，按当前界面语言匹配；忽略大小写、全半角和首尾空格，多关键词同时匹配。结果显示命中的正文片段，空结果可清除或选择目录。
- `?topic=<id>` 可直接定位与收藏；无效主题回退登录与绑定。切换主题保留其他查询参数，支持前进/后退并将焦点移到正文标题。清除搜索保留输入焦点。
- 固定文案通过 `msg`，英文词表覆盖完整正文；更新日期通过 `getLocale()` 格式化。打印按钮只打印当前主题，隐藏网站导航、目录、搜索和业务操作入口。

## 页面排版

- 沿用 Corporate Clean，页头与搜索横向铺满内容区。桌面目录 244px，正文占剩余宽度，间距 28px；1100px 以下目录 208px、间距 20px；900px 以下目录改为共享 Select。桌面目录独立滚动，最大高度为 `max(320px, 100dvh - 330px)`，长正文滚动时保持目录可见，不用长目录撑高短主题。
- 正文容器内边距桌面 28×32px，中屏 24px，600px 以下 20px。主题标题 22px（手机 20px）、步骤 15px/1.85；必要提示使用浅灰底列表，不新增重叠卡片。
- 目录、选择器、搜索清除、打印及业务链接均有至少 44px 的点击高度。当前主题同时以文字加粗、边条和 `aria-current` 表达；键盘焦点可见，跳转即时定位，减少动态效果无需额外动画。
- 只加载静态帮助数据；不因打开说明而读取成员业务记录。页面按现有路由懒加载。

## 内容维护

单一内容来源为 `web/src/modules/system/help-content.json`。修改主题时同步 `web/src/lib/locales/en.ts`，保持主题 ID 稳定；政策变化同步对应业务指南，并核实已发布行为。

从仓库根目录导出中文指南：

```sh
node scripts/export-user-guide.mjs
node scripts/export-user-guide.mjs --check
```

不要直接编辑生成的 `docs/user-guide.zh-CN.md`。`help-content.test.ts` 检查主题 ID、业务链接和动态正文翻译，`help.spec.ts` 覆盖检索、书签、历史、焦点、响应式、打印与访问边界。测试和本轮截图见[交付记录](../history/seat-help-20261020.md)。

# 贷款模块

状态：统一贷款池已发布。贷款以游戏 ISK 为单位，全站固定只有一个统一贷款池，个人或军团可以提交出借额度；借款方是本站成员账号，一个账号的多个绑定角色共用贷款责任。

利息采用现实贷款常见的年名义利率固定单利：管理员在风控设置中配置年利率 bps（100 bps = 1%），申请提交时按 `本金 × 年利率 × 期数 × 间隔天数 ÷ (10000 × 365)` 计算一次，按 ISK 最小单位四舍五入；本金和利息以整数保存，每期等额分摊，最后一期吸收舍入差额。申请同时冻结年利率快照，之后修改规则不会重算已有贷款。出借额度提交后先处于待入金状态；出借方必须向配置的统一托管角色或军团创建完成的纯 ISK 合同，本站核验金额、方向、接取角色和物品为空，并取得全局合同占用后才进入池内现金。贷款审核通过不等于已经放款，放款前还要锁定池余额，放款核验后扣减池余额。

信用资料由系统根据本人历史贷款履约记录评估，评分、总责任额度、无担保额度和规则版本均为系统产物，管理员不能手工修改。个人基础授信还会读取当前账号有效绑定角色的个人钱包收入快照，在可配置观察窗口内汇总收入减支出，按收入负债率、授信期限和评分系数折算，并受个人硬上限约束；缺少足够样本时默认回退到已核验本金池评分，也可在风控设置中改为暂停个人授信。钱包授权只控制证据是否可用，不作为评分因子。最终申请额度仍同时受统一池可用现金限制。当前 `system-v2` 权重为履约 55、负债压力 20、担保/抵押履历 10、PAP 评分 5、资产规模评分 10；授权状态和账号持续时间完全不进入评分。PAP 评分拆为两项：近一年已结束军团活动的活动集结率计 3 分，近 6 个月完整联盟 PAP 月快照中达到联盟月度门槛的月份占比计 2 分；两项按比例取整并分别封顶。缺少活动记录、联盟快照缺失或同步未完成时保持中性，不把不可用证据当作零分。资产数据源尚未接入，资产规模评分固定为 0 分。授权只控制能否读取/刷新证据。系统按已结清贷款、已还分期、当前责任、逾期分期和违约记录计算评分，并在查看贷款页及审批事务中重新评估；存在违约时信用状态暂停。总责任额度以统一池已核验入账的实际现金余额作为本金池基数，按当前信用分动态计算；待核验出借承诺和网站余额不计入本金池。每次审批保存不可变信用评估快照，评分、额度、担保覆盖和抵押覆盖均在审批事务中重新检查。担保邀请金额同时受贷款本金比例和担保人当前可用总责任剩余额度限制，担保人确认时在事务内重新计算总责任剩余额，确认后才占用额度；抵押必须提交已完成的物品交换合同，后台读取并冻结物品快照，管理员批准前保持待处理状态，贷款结清后释放。模块不会自动扣款、自动处置抵押物或把钱包余额当作付款事实。

统一贷款池是固定单例，不提供池创建、切换或额度边界配置入口；模块迁移会按当前军团角色快照自动建立一个开放的军团池，贷款设置由有权限的贷款管理者从所有有效绑定的 EVE 角色中选择个人角色作为合同处理人，不再限制为管理者自己的角色。合同接收方由该角色确定，权限仍按角色所属本站账号校验；未配置有效处理人时禁止合同入金核验。不能把网站余额或未核验的承诺额度当作现金。抵押覆盖额仍不能超过估值乘以已发布规则的折扣，提交值和规则不一致时拒绝审批。

贷款管理权限属于本站权限角色；配置合同处理人的 EVE 角色不会自动授予贷款管理权限。应先在权限管理中给账号授予 `corporation.loan`，再由有权限的贷款管理者选择有效的个人 EVE 角色。

付款接口使用现有 EVE 合同缓存服务。放款合同要求完成状态、完整金额和借款人收款角色匹配；还款合同允许部分金额，服务按最早未清分期分配并保留本金/利息明细。一个游戏合同只能被一个交付模块占用，重复核验返回冲突，不重复入账。

## 接口与权限

- `GET /api/v1/loan/context`：当前账号可见贷款池与信用摘要。
- `GET /api/v1/loan/contributions`、`POST /api/v1/loan/contributions`：查看并提交统一池个人/军团出借额度。
- `POST /api/v1/loan/settings/custodian`：由贷款管理者设置接收合同的个人 EVE 角色；角色必须仍绑定到有效本站账号。
- `POST /api/v1/loan/contributions/{id}/auto-verify`、`POST /api/v1/loan/contributions/{id}/cancel`：按当前账号最近同步的完成合同自动核验，或取消待入金记录。
- `GET /api/v1/loan/cases`、`GET /api/v1/loan/cases/{id}`：本人参与的贷款；管理者可读取其负责的贷款池。
- `POST /api/v1/loan/applications`：成员提交申请，保存固定条款和分期快照。
- `POST /api/v1/loan/cases/{id}/review`：出借方或军团贷款管理者审核，禁止借款人自审。
- `POST /api/v1/loan/cases/{id}/payments`：提交放款或还款合同并立即执行缓存核验。
- `POST /api/v1/loan/cases/{id}/guarantees`、`POST /api/v1/loan/guarantees/{id}/decision`：担保邀请与担保人确认。
- `GET /api/v1/loan/guarantees`：读取当前账号收到的担保邀请。
- `GET /api/v1/loan/guarantees/candidates`：读取可邀请的有效绑定角色；服务端发送邀请时再次解析角色归属，列表不授予担保责任。
- `POST /api/v1/loan/cases/{id}/collateral`、`POST /api/v1/loan/collateral/{id}/decision`：抵押登记与管理审批。
- `GET /api/v1/loan/credit`：读取当前账号的系统信用评估结果；没有人工授信写入接口。
- `GET /api/v1/loan/settings/policy`、`POST /api/v1/loan/settings/policy`：贷款管理者读取或按版本更新收入授信策略，普通成员只能读取当前策略。
- `GET /api/v1/loan/evaluations`：读取当前账号的不可变信用评估快照列表。

军团池的待审申请同时作为 `loan` 来源进入审批中心；审批中心只读聚合并复用本模块的审核接口，个人出借池继续留在贷款页内处理。

贷款页使用同一路由的三个标签页：贷款业务、风控设置、评估记录。业务标签保留出借、申请、担保和抵押弹窗；风控设置仅对贷款管理者开放，可配置年利率、收入观察窗口、收入负债率、授信期限、评分系数、个人硬上限、收入样本门槛、证据有效期、担保/抵押覆盖上限，并设置合同处理人；评估记录展示当前账号不可变的审批评估快照。统一池固定为单例，提交出借、提交借款、邀请担保和登记抵押均通过按钮打开弹窗；担保从有效绑定角色选择，抵押从当前账号可查看的已完成物品交换合同选择，合同所有者和合同 ID 不再手填。申请间隔天数固定提供 1、3、7、14、30 天，后端同样拒绝其他间隔；首期还款时间在实际放款合同核验后按放款时间加所选间隔生成，剩余分期按相同间隔生成。抵押估值使用池配置的固定折扣，覆盖金额由估值和折扣自动计算，后台仍按合同快照和收款方向核验。出借记录以列表展示并由接口直接返回出借角色名字，点击单条记录后才打开详情弹窗。待核验详情只展示创建合同所需的贷款专员角色名字、支付金额和合同备注复制字段；角色 ID 保留在接口和后台用于校验，名称暂不可用时页面才回退显示 ID。合同类型与无物品要求作为说明。合同完成并同步后由系统自动核验，不提供核验按钮；只有入金合同核验完成的额度才显示为可放贷余额。出借角色和收款角色从当前账号已绑定角色的昵称下拉框中选择，提交时由系统使用对应 ID；页面不要求用户记忆角色 ID。借款申请提交成功后刷新列表。信用评分和授信额度由系统根据履约记录、军团活动集结率、联盟 PAP 满足情况自动评估，页面展示两项 PAP 评分因子；资产规模评分当前固定为 0 分，不能用钱包余额替代。任何成员可提交个人出借额度，军团额度要求对应军团管理权限；审批事务会重新评估信用、资金、担保和抵押条件。收到担保邀请的成员可在贷款页接受或拒绝，接受前重新检查责任额度。

写请求由宿主会话鉴权和 CSRF 保护；业务服务继续检查贷款对象、出借方、借款方、绑定角色和合同范围。数据库迁移为 Goose 70–73、79–82，模块只有在 `MODULES` 启用 `loan` 后才显示页面。

首期仍需用真实 EVE 合同验证方向、金额、部分还款、重复占用和授权失效边界；生产部署和入口启用不代表真实合同闭环已验收。

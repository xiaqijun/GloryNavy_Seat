# 贷款模块

状态：统一贷款池已发布。贷款以游戏 ISK 为单位，全站固定只有一个统一贷款池，个人或军团可以提交出借额度；借款方是本站成员账号，一个账号的多个绑定角色共用贷款责任。

采用固定总利息、按期等额分期。本金和利息以 ISK 最小单位整数保存，每期分别保存两项，最后一期吸收舍入差额。出借额度提交后先处于待入金状态；出借方必须向配置的统一托管角色或军团创建完成的纯 ISK 合同，本站核验金额、方向、接取角色和物品为空，并取得全局合同占用后才进入池内现金。贷款审核通过不等于已经放款，放款前还要锁定池余额，放款核验后扣减池余额。

信用资料由系统根据本人历史贷款履约记录评估，评分、总责任额度、无担保额度和规则版本均为系统产物，管理员不能手工修改。当前 `system-v2` 权重为履约 55、负债压力 20、担保/抵押履历 10、PAP 辅助 5、资产规模辅助 10；授权状态和账号持续时间完全不进入评分。PAP 辅助证据合并本站已确认的军团点名 PAP 与最近一年内最新的完整联盟 PAP 快照；联盟同步缺失、过期或未完成时保持中性，不把未完成同步当作零分。PAP 缺失、资产快照缺失或过期只表示证据不可用，不产生负分；授权只控制能否读取/刷新证据。系统按已结清贷款、已还分期、当前责任、逾期分期和违约记录计算评分，并在查看贷款页及审批事务中重新评估；存在违约时信用状态暂停。总责任额度以统一池已核验入账的实际现金余额作为本金池基数，按当前信用分动态计算；待核验出借承诺和网站余额不计入本金池。每次审批保存不可变信用评估快照，评分、额度、担保覆盖和抵押覆盖均在审批事务中重新检查。担保由担保人主动确认，担保确认会占用其责任额度；抵押必须提交已完成的物品交换合同，后台读取并冻结物品快照，管理员批准前保持待处理状态，贷款结清后释放。模块不会自动扣款、自动处置抵押物或把钱包余额当作付款事实。

统一贷款池是固定单例，不提供池创建、切换或额度边界配置入口；模块迁移会按当前军团角色快照自动建立一个开放的军团托管池，页面只提交出借/借款金额。入金合同的托管方由该固定池记录确定，不能把网站余额或未核验的承诺额度当作现金。抵押覆盖额仍不能超过估值乘以已发布规则的折扣，提交值和规则不一致时拒绝审批。

付款接口使用现有 EVE 合同缓存服务。放款合同要求完成状态、完整金额和借款人收款角色匹配；还款合同允许部分金额，服务按最早未清分期分配并保留本金/利息明细。一个游戏合同只能被一个交付模块占用，重复核验返回冲突，不重复入账。

## 接口与权限

- `GET /api/v1/loan/context`：当前账号可见贷款池与信用摘要。
- `GET /api/v1/loan/contributions`、`POST /api/v1/loan/contributions`：查看并提交统一池个人/军团出借额度。
- `POST /api/v1/loan/contributions/{id}/deposit`、`POST /api/v1/loan/contributions/{id}/cancel`：核验入金合同或取消待入金记录。
- `GET /api/v1/loan/cases`、`GET /api/v1/loan/cases/{id}`：本人参与的贷款；管理者可读取其负责的贷款池。
- `POST /api/v1/loan/applications`：成员提交申请，保存固定条款和分期快照。
- `POST /api/v1/loan/cases/{id}/review`：出借方或军团贷款管理者审核，禁止借款人自审。
- `POST /api/v1/loan/cases/{id}/payments`：提交放款或还款合同并立即执行缓存核验。
- `POST /api/v1/loan/cases/{id}/guarantees`、`POST /api/v1/loan/guarantees/{id}/decision`：担保邀请与担保人确认。
- `GET /api/v1/loan/guarantees`：读取当前账号收到的担保邀请。
- `POST /api/v1/loan/cases/{id}/collateral`、`POST /api/v1/loan/collateral/{id}/decision`：抵押登记与管理审批。
- `GET /api/v1/loan/credit`：读取当前账号的系统信用评估结果；没有人工授信写入接口。

军团池的待审申请同时作为 `loan` 来源进入审批中心；审批中心只读聚合并复用本模块的审核接口，个人出借池继续留在贷款页内处理。

贷款页不提供统一贷款池配置，也不提供人工信用配置。统一池固定为单例，提交出借、提交借款、邀请担保和登记抵押均通过按钮打开弹窗；物品抵押不接受手工物品清单，后台按合同快照核验。借款申请提交成功后刷新列表。信用评分和授信额度由系统根据履约记录、已确认 PAP 和可用资产快照自动评估，页面只展示当前结果及辅助因子；资产快照 provider 未提供时资产因子保持中性，不能用钱包余额替代。任何成员可提交个人出借额度，军团额度要求对应军团管理权限。只有入金合同核验完成的额度才显示为可放贷余额；审批事务会重新评估信用、资金、担保和抵押条件。收到担保邀请的成员可在贷款页接受或拒绝，接受前重新检查责任额度。

写请求由宿主会话鉴权和 CSRF 保护；业务服务继续检查贷款对象、出借方、借款方、绑定角色和合同范围。数据库迁移为 Goose 70、71、72，模块只有在 `MODULES` 启用 `loan` 后才显示页面。

首期仍需用真实 EVE 合同验证方向、金额、部分还款、重复占用和授权失效边界；生产部署和入口启用不代表真实合同闭环已验收。

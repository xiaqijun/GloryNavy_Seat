# EVE Sentry 预警平台密钥与时间计费

2026-10-20 生产核查发现收费故障：远端消费证据写入受旧唯一索引阻塞，且历史逐区间取整存在累计偏高。下文说明接口与设计口径，不代表完整实账验收已通过；当前证据和修复边界见[核查记录](../history/sentry-billing-audit-20261020.md)。

本站负责密钥创建/更新、账号归属、按小时价格和管理员收费开关。密钥明文以服务端 `EVE_TOKEN_KEY` 派生密钥加密保存，仅在当前账号的受保护列表响应中返回；不写入浏览器存储、URL 或日志。页面只提供复制和更新按钮，不自动轮换。

迁移前已创建的旧密钥没有可恢复的明文，需手动更新一次完成加密保存；更新后可随时复制。

## API

- `GET/POST /api/v1/sentry/keys`：读取或创建当前账号密钥。
- `POST /api/v1/sentry/keys/{id}/rotate`：手动更新密钥，加密保存并返回完整内容；之后列表仍可读取并复制。
- `GET/PUT /api/v1/sentry/time-pricing`：管理员读取或保存预警价格、监控奖励价格（果壳币/小时）及收费开关。
- `GET /api/v1/sentry/alert-usage`、`GET /api/v1/sentry/alert-consumptions`：读取账号级余额、花费和奖励流水。
- `GET /api/v1/sentry/monitor-rewards`：读取最近奖励区间，并返回全部已入账奖励的 `total_minor` 和 `total_count`；列表只展示最近记录。

收费开关保存时同步调用 Sentry 的 `PUT /api/v1/integrations/seat/alert-consumption`。远端同步失败不会提交本地开关。

## 计费口径

Goose 107 防线已实现、待发布，当前收费保持关闭：新结算的 `system_id` 必须为规范正整数 ID；已结算及旧合并区间覆盖的重放保留原语义。此处校验 ID 格式，具体星系归属仍由上游证据提供，不代表已校验客户端选中范围。

恢复收费使用价格审计中最近一次真实关闭→开启的时间；普通改价不重置窗口。仅完全位于本次开启窗口的区间允许新扣费。此前未结算、暂停及跨开启边界的区间在 `sentry_client_usage_exclusions` 逐 usage 保存账号、原始区间/秒数/星系、原因与开启审计后才允许游标前移，不追扣。关闭时不写新的排除记录；缺开启边界、无效星系、审计失败或证据漂移均失败并保留游标。

门禁、排除证据与币账决定共用结算事务，关闭操作等待在途事务完成。已结算或已排除的相同证据可重放，排除记录不得改载荷重新收费。账号合并保留首次 `original_account_id` 并参与预览指纹。旧的未结算 reserve 若被窗口排除，原账保持不变，不自动释放；本轮生产已核实没有此类在途预留。已有排除审计后禁止 107 Down 或运行忽略窗口/排除证据的旧程序。

Goose 106 起，后续消费按账号、星系、冻结价格版本及单价组合持久化向上取整的余额：每段只收累计费用向上取整后的增量。例如每小时 2 币的 60 个 1 秒区间累计收 0.04 币，不再逐段收 0.01 币。区间可能为 0 分，仍保存 `settled` 证据；只有正金额写币流水。原始 `usage_id` 作为稳定结算身份，分页、重试和重启不重置余量；预留、消费证据、币账及余量同事务提交，余额不足或任一步失败均回滚。

新的累计余量从空表起算，价格版本或冻结单价切换使用独立余量。旧账不重算、不退款、不补扣；旧已结算合并区间完整覆盖的原始证据重放直接跳过，部分重叠拒绝处理。账号显式合并迁移并相加余量，保留原账归属和预览指纹；可能超过 1 分的合并余量抵扣后续使用，不即时改币。完整迁移和回退限制见[修复记录](../history/sentry-billing-rounding-20261024.md)。

新收费只读取 Sentry 的 `GET /api/v1/integrations/seat/client-usage`。每条记录是认证客户端相邻有效心跳之间的服务端在线区间，Seat 按区间秒数乘小时价格幂等结算。事件次数、事件投递、ACK、远端预付授权、释放和退款不参与收费，相关接口与历史兼容表已删除；Seat 内部仅保留结算所需的原子币账引用。

监控奖励读取 `GET /api/v1/integrations/seat/monitor-contributions`，每个星系只有主节点贡献有效在线时长。同一账号选择多个预警星系时，各星系独立计量并合并到账号级果壳币流水。

服务令牌只保存在两端服务端环境中，不进入浏览器或文档；当前生产入口为 `https://seat.glorynavy.com`。域名迁移时同步 `SENTRY_INTEGRATION_URL`，避免服务 POST 经过旧站重定向。

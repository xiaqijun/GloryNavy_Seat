# 按军团定期清理角色

## 2026-10-17：配置军团与业务可见范围

清理规则按名称搜索、多选已同步军团，页面不再要求输入 ID。名称候选来自本地 EVE 军团职务快照（包括过期的名称标签），名称仅用于选择，不作为授权事实。HTTP/数据库继续保存十进制字符串/整数 ID；旧名单原样保留，缺名称显示待同步且可以移除。

保存的 `corporation_ids` 同时限定军团业务范围，独立于每周清理开关。站点管理员只能访问名单内军团；普通成员及军团管理员只能访问名单与本人有效绑定角色所属军团的交集，仍需原业务权限。本站角色的全局、军团或联盟授权均不得扩大该范围。多角色按账号取所属军团并集，过期或失效授权不作为所属依据。空名单不显示任何业务军团；管理员仍可进入成员页配置。舰船损失/福利、军团运营/考勤、技能/配装库、军团钱包/合同/建筑/贷款权限在后端逐请求核验，直接填写其他军团 ID 也拒绝。

个人账号管理、个人历史记录与管理员按成员读取已交付个人数据继续遵循各自的对象权限。该规则不增加 SSO 登录准入门禁，也不提前执行清理。保存后当前页面缓存刷新；其他会话下次请求重新校验。无新迁移，Goose 90；旧程序不识别业务范围限制，回退会重新扩大范围。

## 配置和范围

当前站点管理员在 `/members` 的“清理规则”按名称搜索并选择允许保留的已同步军团（最多 50 个），预览名单后启用并保存。默认关闭、名单为空；启用时禁止空名单。每次启用状态的保存将下次运行设为保存后 7 天，之后每次完成再安排 7 天后；关闭清空下次时间。时间戳存为 UTC，页面按当前语言和浏览器时区显示。没有立即清理接口。

逐角色判断，不因同账号有本团主角色而保留外团小号，主角色和最后一个角色也在范围内，管理员角色亦无豁免。预览展示总清理/保留/待核实数量和前 100 个候选角色；预览不产生删除，执行时重新读取事实。只允许当前管理员读写/预览，`access.manage`、`eve.sync.manage` 或游戏职务均不能代替；PUT 和 POST 同时校验 Origin/CSRF，版本冲突返回 409。

## 删除与保留

- 仅使用有效绑定、同游戏所有者、有效期内且军团一致的角色资料和职务快照。凭据须 ready 且有军团职务 scope，profile/authorization 同步目标须属于当前授权代次、存在成功记录、无失败且未 blocked/failed。缺失、过期、同步失败、归属异常及不一致均跳过，不将未知当作外团。
- 解除绑定、删除该角色本地 ESI 凭据及随凭据保存的缓存/在线数据、个人合同缓存，撤销该角色产生的本站会话和未消费授权 flow，清除受影响账号待确认合并请求。没有向 CCP 发起远程撤权或游戏物品操作。
- 主角色移除后按角色 ID 选取剩余有效角色；无剩余有效角色则清空主角色并撤销全部会话。账号、本站权限配置、社区资料、贷款债务、PAP/币流水、申请及交付快照保留。普通个人解绑仍禁止直接删除主角色/最后一个角色。
- 保留被清理角色的账号归属和 owner hash。之后同一游戏所有者重新完成 SSO，恢复原账号；已有主角色不被覆盖，无主角色时设为主角色。禁止普通跨账号绑定和不同 owner 接管。显式账号合并迁移这些保留归属，同时保留 original_user_id；并发合并使归属变化时拒绝本次恢复，重新发起登录。
- 此规则是每周解除绑定，不是登录军团准入规则。完成新 SSO 的角色可重新绑定；若仍不符合名单，在后续周期再次清理。

## 后台与迁移

Goose 90 新增 identity 私有策略、归属保留和审计表。宿主将 EVE 的 `CleanupMembership`、`RemoveCharacterTx` 和当前管理员检查注入 identity；不跨模块读取私有 store。共享 River 注册 `identity.corporation-cleanup.v1`，每分钟扫描到期策略，每任务最多处理 25 个账号，使用 `eve_control` 队列；需启用 eve 及现有后台运行器，无新增环境变量或 cron。

每账号一个事务：策略行排他锁、按 ID 排序的角色 advisory 锁、账号锁、复查角色列表、凭据锁，然后核对事实、删除和推进持久游标。凭据锁与同步发布保持顺序；网络抓取不进入事务。失败回滚当前账号，已提交账号不重复；重试/进程重启继续游标。管理员修改规则会中止旧游标并重新安排周期；已完成删除不恢复。审计记录配置版本、移除原因/归属和完成计数，页面区分最近完成结果和当前运行状态。

接口：`GET/PUT /api/v1/identity/corporation-cleanup`、`POST /api/v1/identity/corporation-cleanup/preview`，契约见 [OpenAPI](../../api/openapi.yaml)。错误为 400 `invalid_cleanup`、401 未登录、403 非管理员/CSRF、409 `cleanup_conflict`、503 `cleanup_unavailable`。

回退前关闭清理并取消未结束的 `identity.corporation-cleanup.v1` River 作业。已有保留归属后禁止回退不识别此表的旧程序，否则重新登录会创建错误账号；Down 在保留归属非空时拒绝。需要恢复时使用发布前备份及匹配程序，不单独删除保留归属或业务记录。

## 验证边界

数据库和模拟浏览器验证记录见项目状态。生产首次启用需由管理员选择白名单、核对预览并保存；首次周期完成后再核对实际审计和会话失效。测试数据不能替代真实角色清理验收。

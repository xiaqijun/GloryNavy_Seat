# EVE Sentry 接入方案

状态：2026-10-04。收费和奖励统一按服务端确认的有效在线时长计算。事件次数、事件投递、客户端 ACK、远端预付授权、释放和退款不属于当前业务，也不保留历史兼容接口或数据表。

## 职责

- Sentry：验证密钥，记录认证客户端在线区间，记录每个星系主节点的监控贡献区间，并以服务令牌提供分页只读接口。
- Seat：维护账号和 `system_id` 归因、管理员小时价格和收费开关，在 exchange 内完成果壳币扣款与奖励入账。
- 前端：在同一个消费区域展示余额、预警价格、监控奖励价格和累计花费/奖励；配置收费使用弹窗，普通成员只读。

## 远端接口

- `GET/PUT /api/v1/integrations/seat/alert-consumption`：持久化收费门禁。
- `GET /api/v1/integrations/seat/client-usage`：认证客户端相邻有效心跳在线区间。
- `GET /api/v1/integrations/seat/monitor-contributions`：主节点监控贡献区间。

接口只接受后端 Bearer Token，不传递价格、余额或币额。事件、投递、ACK、alert-grants 及其游标接口已删除。

## 计费规则

每个星系独立计量。同一星系只有主节点在线时长产生奖励；备用节点不重复奖励。预警选择 N 个星系时，各星系在线时长分别按预警小时价格扣款，结果合并到账号级果壳币流水。连续区间按客户端、账号、星系和时间边界幂等合并，重复提交不重复扣款或发奖。

收费开关关闭时不产生新的扣款；监控奖励价格和预警价格都由管理员按果壳币/小时配置。价格变更只影响新的结算区间。

## 验收

1. 新库只建立在线区间、主节点贡献和收费门禁表；旧事件/授权/投递表可以删除。
2. 使用测试账号验证一个星系的在线扣款、一个主节点的奖励和重复区间幂等。
3. 验证 Seat 前端开关与 Sentry 门禁同步，服务重启后状态保持。
4. 不执行事件、ACK、授权释放或退款验收，不把历史阶段文档作为当前能力依据。

## 根因与修复

生产只读检查：兑换 #2（MP5K，21 份 ISK）为 pending / waiting_contract，角色仍绑定到原账号，fresh 审批索引 bucket=fulfillment；#1 为已取消记录。以当前真实管理员权限和当前绑定调用服务，来源原查询返回 1 笔待发放、1 笔历史记录，统一索引却均返回 0。

`approval/internal/store.Scope.Corporation` 的 `omitempty` 将无军团来源的空值省略。索引 SQL 将 `scope->>'corporation'` 与空军团行比较，实际是 NULL 与空字符串比较，合法账号/角色绑定也被过滤。改为始终序列化该字段，保留 `All=false` 与 `RestrictBindings=true`；不通过扩大到全部范围来恢复可见性。

普通兑换仍在“待发放”；只有取消申请需要“待审批”，终态显示在“已处理”。本人待办、失效绑定、不同账号/接收角色以及有军团归属的越界记录继续排除；兑换详情仍走来源专用读取。

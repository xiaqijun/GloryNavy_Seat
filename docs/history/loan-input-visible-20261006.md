# 贷款输入控件可见性验收（2026-10-06）

贷款页面原先引用了主题中不存在的 `--input`、`--ring` 等变量。浏览器会丢弃包含无效变量的边框和焦点声明；管理员表单的背景色又与页面背景接近，导致输入框几乎不可见。

本次前端样式改为使用明确的主题回退值：字段使用卡片白底和对比边框，控件最小高度为 44px，补充悬停、禁用、占位符和键盘焦点状态，并为标题、提示和操作区补充窄屏换行约束。后端、数据库和 API 契约没有变化。

验证使用本地生产构建同源页面和受控 API fixture，不写入生产数据。中文和英文各在 1440、1000、375、320px 渲染，共 8 个场景；每个场景检查 19 个输入/选择控件的 1px 实线边框、至少 44px 高度、可用宽度，聚焦时 2px 蓝色焦点环，以及根页面没有横向溢出。8 个场景全部通过，并人工查看了 1440px 和 375px 中文截图。

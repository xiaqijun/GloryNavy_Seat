# LP 兑换查询

2026-10-21 用户要求将此前快递参考项目的 LP 查询接入工具菜单。本轮只做 NPC 忠诚点商店与收益查询，不涉及订单、审批、个人 LP、果壳币、游戏合同或发放。参考 [glory-navy](https://github.com/dearosmanthus/glory-navy) 提交 `955c2dedb346312d14982f12b3201ff8f22c5828` 的查询行为独立实现，未复制其无许可证源码或资产。

## 实现

新增私有 `lp` 模块及 `/lp` 页面，三项只读 API 保留会话与资料门禁。新 LPDataService 校验当前活动官方 SDE ZIP 的 SHA-256，解析 NPC、阵营和蓝图；保留既有 SDE 导入和回退机制。物品名称使用已有 StaticDataService，商店和备用行情使用共享 ESI 缓存、观测与限流，LP 查询不使用个人 token。

界面遵循现有 Corporate Clean，加入工具导航分组、双语搜索、排序、分页、五个市场、买卖单依据、税费和可展开材料。蓝图使用 ME 0 配方与流程数，缺配方或缺必要报价不显示完整收益，LP / AK 分别比较。固定 HTTPS Fuzzwork 优先，服务器不可达时以官方 ESI 同空间站买卖单备用；短期限流延迟遵守网关时间，网络失败不伪装成零价。说明见[中英文契约](../integrations/lp.zh-CN.md)与[页面记录](../ui/lp.md)。

## 本轮验证

- 独立 PostgreSQL 18.6 临时数据库：LP 5 项、SDE / LP 10 项、宿主注册/权限/元数据/资料门禁相关 5 项顶层测试通过，均带 race；最新行情调整后重跑 LP 与宿主 LP 定向测试。`go vet` 覆盖 lp、eve 和 app。
- 前端 TypeScript、定向 oxlint、LP 计算与双语词表共 10 项测试、Vite 构建和公开首页预渲染通过。最终构建用 Playwright 跑 18 项中英文检查，覆盖桌面/手机/320px、搜索、材料、分页、空结果、筛选、键盘、无效税费、行情失败与重试；桌面与窄屏截图已人工查看。
- 直接调用真实来源服务：活动 SDE 3632936 含 280 个 NPC 军团、27 个阵营、5100 个蓝图；姐妹会 102 项兑换，132 个名称、9 项蓝图。126 种相关物品完整分批查询，124 种有卖单报价。Fuzzwork 从应用机和香港连接失败，使用 ESI 备用。首次备用请求遇到 network_error，重新查询完整成功；保留重试与错误状态，不保证上游始终可用。
- 来源实测只读业务资料；共享 ESI 网关照常记录公共缓存和请求预算，没有创建测试订单、扣币或发送游戏邮件。浏览器验收使用模拟会话/API，真实已登录线上浏览器视觉验收尚未完成。

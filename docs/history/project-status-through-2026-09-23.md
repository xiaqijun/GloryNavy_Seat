## 产品范围

自研 EVE 军团平台，采用 Go 模块化单体、React 中文界面和 PostgreSQL。目标是覆盖角色身份、军团权限、社区确认、游戏数据与报表。游戏环境为国际服 Tranquility。

成员模型需支持一人持有多个 EVE 游戏账号：一个本站账号绑定多个角色，社区资料共用，游戏授权按角色独立管理。已实现显式添加角色、主角色选择、按角色重新授权和解绑保护，详见[多角色设计](../architecture.md#一人多游戏账号与多角色绑定)。

已核对 SeAT 固定提交，补齐一个主角色与多个小号、任一角色登录、显式绑定、解绑保护及归属冲突设计；主角色与登录/查看角色分离。中英文[参考及验收规则](../integrations/seat-multi-character.zh-CN.md)已同步实现；迁移 `00007` 和对应 API 已交付，账号合并仍未开放。

登录页已使用 Glory Navy（G.N.V，军团 ID `98530802`）的官方图标。品牌图标不代表系统已实施该军团成员的准入限制；业务访问仍由后端授权规则决定。

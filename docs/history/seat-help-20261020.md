# 站内使用帮助（2026-10-20）

用户选择将 SeAT 使用文档放在站内。新增 `/help`，侧栏底部提供固定入口；入门、日常使用、业务办理、专员与管理四组共 17 个主题，支持当前语言全文检索、主题链接、手机目录与打印本节。

内容以当前业务实现与集成指南为依据，覆盖撤销与取消退款区别、日/周/月补损确认、抵押八折估值、购舰合同选择、结算编号、PAP 与果壳币、邮件提醒和专员权限。无后端、数据库、授权范围或业务状态变化。本次文档不能替代真实游戏合同、邮件、PAP 的联调证据。

# 快递合同估价提速

2026-10-23 用户确认反馈的是快递页面估价。实际日志近期成功请求 2.5–20 秒，多次在 8 或 28 秒后 503。原客户端每次都 GET 首页取得匿名 XSRF Cookie，再 POST 报价；重复输入也完整重走两次请求。应用机旧源码实测同一合成清单（三钛合金 1 件）依次 12.94、4.32、3.20 秒；首次首页响应头 5.41 秒，报价响应头 7.53 秒。只读估价不会创建游戏合同或本站订单。

## 修改与边界

- 匿名服务方会话复用最多 5 分钟，尊重 Cookie 提前到期；收到明确 403 后下次重新取会话，不自动重放 POST。本站身份、Cookie 和 EVE token 不转发。
- 完整报价在进程内保存最多 60 秒／128 项，用首尾去空白后的 SHA-256 键，不持久化原清单。未知项目与失败结果不缓存，过期不兜底为旧价；修改清单或数量换键。
- 相同请求合并，其他请求仍最多两路，取消一个读者不影响同组其他读者。共享调用最多 28 秒；返回值深拷贝，防止读者修改共享缓存。上游首次查询仍会受网络和第三方行情速度影响。
- 保留原金额、体积、失败项目、Janice URL 验证和主站鉴权/CSRF。无迁移、配置或前端改动，回退只影响速度，不涉及账目。

# 公开首页分屏翻页（2026-10-19）

## 范围

用户明确要求类似采星者的翻页式首页，并减少文字堆砌。仅改公开 `/` 的前端内容组织和交互，详细设计见[首页](../ui/homepage.md)。后端、公开接口、登录流程、权限和业务数据不变。

五屏为首屏、军团介绍、军团活动、成员保障、加入我们。沿革和公开数据合并，活动/保障各三项短句，入团要求默认折叠。原生滚动吸附、动态页头避让、页码及菜单高亮；内容可超出一屏，不裁切。取消本页 GSAP，离开后移除滚动规则。
